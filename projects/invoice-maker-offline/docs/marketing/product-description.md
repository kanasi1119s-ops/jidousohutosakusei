# 商品説明文案（BOOTH/Gumroad用・有料版を用意する場合の草稿）

**【買い切り】オフラインで使える請求書メーカー（適格請求書の記載チェック付き）**

ブラウザで開くだけで使える請求書・見積書・納品書・領収書の作成ツールです。登録不要、入力データは端末の中にだけ保存されます。

■ できること
- 税率ごと（10%・8%・非課税）の集計と、税率ごとに1回の端数処理
- 適格請求書の記載事項チェック（7項目）
- 登録番号（T＋13桁）の形式確認
- 源泉徴収の差引表示、PDF保存（印刷機能）、明細CSV、JSONバックアップ

■ ご注意
- 税務・法律上の助言ではありません。内容は発行者ご自身でご確認ください。
- データはブラウザ内に保存されます。定期的にバックアップを保存してください。
