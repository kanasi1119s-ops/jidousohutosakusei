# SNS告知文（草稿）

**パターン1**
登録不要・オフラインで使える請求書メーカーを作りました。入力した内容はブラウザの外に出ません。適格請求書の記載事項チェック付き。PDF保存もできます。 #請求書 #インボイス #個人事業主

**パターン2**
請求書を出す前のチェックに。発行者名・登録番号・取引年月日・税率別の税額…7項目の記載漏れを確認できます（税率ごとに1回の端数処理で計算）。 #インボイス制度 #フリーランス

**パターン3**
クラウドに取引先情報を預けたくない人へ。ブラウザだけで完結する請求書ツール。一度開けばオフラインでも作成できます。 #請求書作成 #オフライン
