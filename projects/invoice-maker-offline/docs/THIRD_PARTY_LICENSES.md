# サードパーティライセンス

**配布物（`dist/`）に含まれるサードパーティコードはありません**（ランタイム依存パッケージなし。ビルドは独自コードのみをバンドル）。
以下は開発時のみ使用する依存（node_modules）のライセンス別パッケージ数（2026-10-22 時点、推移的依存を含む）。

| ライセンス | 件数 |
|---|---|
| MIT | 81 |
| Apache-2.0 | 7 |
| BSD-2-Clause | 2 |
| BSD-3-Clause | 2 |
| ISC | 3 |
| MIT-0 | 1 |
| MPL-2.0 | 2 |

GPL/AGPL 等の強いコピーレフトは含まれません。MPL-2.0 はビルド時ツールの一部（ファイル単位のコピーレフト）で、
配布物には含まれないため提供形態との衝突はありません。正確な一覧は `npm ls --all` と各 `package.json` で確認できます。
