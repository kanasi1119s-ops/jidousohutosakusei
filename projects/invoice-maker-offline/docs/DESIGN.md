# 設計

## 企画（PdM）
- **コンセプト**: 登録不要・オフラインで使える、適格請求書の記載要件チェック付き請求書メーカー
- **ターゲット**: フリーランス・個人事業主・小規模事業者（取引先に請求書を出すが、クラウド会計に預けたくない／簡易に済ませたい人）
- **サイト形態**: W1。理由: 計算・書類生成はすべてブラウザで完結し、サーバー・DBが不要。運用コストが最小
- **スコア 20/25**: 需要4 / 実装難易度4 / 法的リスク4 / 差別化3（類似の無料ツールが既に複数ある） / 運用コスト5
- **収益化仮説**（保証ではなく検証対象）: 無料公開＋広告なし。有料版（買い切り：取引先台帳・複数ロゴ/印影・テンプレート）、寄付
- **MVPに含まない**: 取引先台帳、ロゴ/印影画像、電子帳簿保存法対応、会計ソフト連携、有料ライセンス認証、サーバー同期

## 画面
単一ページ: 書類情報 / 発行者情報 / 明細 / 計算結果 / 記載要件チェック / プレビュー・出力 / 保存・バックアップ

## データモデル（`src/types.ts`）
- `AppData { version:1, issuer, docs[], draft }` を localStorage に JSON 保存
- `InvoiceDoc`: id, docType, number, issueDate, dueDate, clientName, items[], rounding, withholding, notes, updatedAt
- `LineInput`: description, quantity, unitPrice（文字列のまま保持。小数3桁まで）, taxRate(10|8|0)

## 計算仕様（`src/calc.ts`）
- 数量・単価は「1000倍の整数（BigInt）」で扱い浮動小数点誤差を避ける。明細金額＝数量×単価を選択した端数処理で円単位に丸める
- 税額＝税率ごとの税抜合計×税率を**1回だけ**端数処理（適格請求書の端数処理ルール）
- 負の値（値引き）は絶対値に対して端数処理（0方向への切捨て）
- 源泉徴収: 税抜合計に対し 100万円以下 10.21%、超過 20.42%、1円未満切捨て
- 上限: 明細100行、数量100万、単価10億円、明細金額1兆円

## 外部通信ゼロ
CSP（`default-src 'self'`）で外部通信を禁止。外部フォント・CDN・解析なし。
