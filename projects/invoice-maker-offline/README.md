# invoice-maker-offline（請求書メーカー）

請求書・見積書・納品書・領収書を作成し、**適格請求書（インボイス）の記載要件をチェック**できる、
登録不要・オフライン対応のWebサイトです。

- **サイト形態**: W1（静的サイト／ブラウザ完結。サーバー不要）
- **データの保存場所**: ブラウザの `localStorage`（キー `invoice-maker-offline:data:v1`）のみ。外部送信なし
- **バックアップ**: 画面から JSON をエクスポート／インポート。明細は CSV（BOM付きUTF-8）で保存可能
- **PDF**: 印刷画面で「PDFに保存」（外部ライブラリ不使用）

## 主な機能
- 税率（10% / 8%軽減 / 非課税）ごとに合計し、**税額は税率ごとに1回だけ端数処理**（切捨て・四捨五入・切上げ）
- 源泉徴収（10.21%、100万円超の部分は20.42%）の差引表示
- 適格請求書の記載事項チェック（発行者名・登録番号・取引年月日・取引内容・税率別合計・税額・宛名）
- 登録番号（T＋13桁）の形式検証と法人番号チェックディジットの整合確認（国税庁の公表サイトでの照合は人が行う）
- 全角数字入力に対応、PWA でオフライン動作

## 起動・テスト・ビルド
```bash
npm ci
npm run dev          # 開発サーバー
npm run check        # 型チェック
npm test             # ユニットテスト（Vitest）
npx playwright install chromium   # 初回のみ
npm run test:e2e     # E2E（Playwright。ビルドしてpreviewを起動）
npm run build        # dist/ に静的ファイルを出力（相対パスなのでサブディレクトリ配置可）
```
