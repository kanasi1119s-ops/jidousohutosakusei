# 設計ドキュメント: 消費税 納税額シミュレーター

## 1. 企画（PdM）
- **背景**: 令和8年度税制改正で、インボイスの2割特例は2026年9月30日を含む課税期間で終了し、個人事業者に
  限り2027・2028年分の「3割特例」が新設されると解説されている。あわせて免税事業者等からの仕入れの経過措置が
  2026年10月から70%へ縮小する。個人事業者・フリーランスにとって「どの方式が有利か」の需要が高まる時期と判断。
  （Web検索で税理士事務所等の解説記事を確認。国税庁サイトは本環境から接続できず一次確認は未了）
- **ターゲット**: 課税事業者（インボイス登録済み）の個人事業主・フリーランス。
- **サイト形態**: W1（静的・ブラウザ完結）。理由: 計算のみでサーバー処理が不要、機微な売上データを外部に出さない価値がある。
- **収益化仮説**: 無料版＋広告なし。将来は複数パターン保存・PDF出力・買い切り版を検討（今回は未実装）。

### 採用スコア（20/25、採用ライン18）
| 観点 | 点 | 備考 |
|---|---|---|
| 需要 | 4 | 制度改正直後で解説記事が多い。検索ボリュームは未計測 |
| 実装難易度 | 5 | 計算ロジックのみ |
| 法的リスクの低さ | 3 | 税務情報のため免責・一次情報確認が必須 |
| 差別化 | 3 | 解説記事は多いが、方式比較＋登録不要＋オフラインの競合は網羅調査できていない |
| 運用コスト | 5 | 静的サイト |

### 却下・保留案
- インボイス請求書ジェネレーター: 無料・買い切りの競合が多く（BOOTH等に「登録不要・オフライン」の買い切り品あり）差別化が弱い → 保留。

## 2. スコープ
含む: 年分選択（2026〜2028）、登録有無、基準期間売上による適用判定、10%/8%売上・仕入、免税事業者等からの仕入（経過措置割合）、
簡易課税の事業区分（単一）、4方式の比較、JSON/CSV入出力、PWA。
含まない: 複数事業区分の併用（75%/90%特例）、中間納付、法人、特定期間判定、PDF出力。

## 3. 計算仕様
- 売上税額 = floor(税込10%売上×10/110) + floor(税込8%売上×8/108)。仕入税額も同様。免税事業者等からの仕入は税額×経過措置割合。
- 3割特例=売上税額×30%、2割特例（2026年分）=×20%、簡易課税=売上税額×(1−みなし仕入率)、原則=売上税額−仕入税額。
- 納付税額は消費税(国税)78:地方消費税22に按分し、それぞれ100円未満切り捨て。マイナスは還付の目安。
- 適用判定: 特例は登録済み＆基準期間課税売上1,000万円以下、簡易課税は5,000万円以下。「最有利」は適用可能な3方式の最小値（免税は参考扱い）。

## 4. 構成
TypeScript + Vite（vanilla DOM）。`src/calc.ts`（計算）、`thresholds.ts`（制度パラメータ）、`storage.ts`、`csv.ts`、`main.ts`。
テスト: Vitest（ユニット＋ランダム整合性）、Playwright（E2E、デスクトップ/モバイル）。
