# 設計書

## コンセプト
「2026年10月からインボイス経過措置が80%→70%に変わった。仕入日ごとに控除額をまとめて確認したい」
個人事業主・小規模事業者・経理担当者向けの、登録不要・オフライン対応の計算サイト。

## サイト形態
**W1（静的サイト／ブラウザ完結）**。理由: 計算のみでサーバー処理が不要。運用コストほぼゼロ。入力（取引先名・金額）を外部に出さないことが価値。

## スコアリング（25点満点）
| 観点 | 点 | 根拠 |
|---|---|---|
| 需要 | 4 | 2026/10/1に控除割合が改正・適用開始。税理士事務所等の解説記事が多数あり関心が高い |
| 実装難易度 | 5 | 純粋な日付判定と税額計算でMVPが短時間で作れる |
| 法的リスクの低さ | 4 | 計算のみ。税務助言ではない旨の免責が必須。一次情報確認は人間 |
| 差別化 | 3 | 会計ソフトは対応済みだが、CSV一括・登録不要・オフラインの手軽な単体ツールは少ない |
| 運用コストの低さ | 5 | 静的ホスティングのみ |
| **合計** | **21** | 採用基準18点以上 |

## 却下・保留した案
- ふるさと納税上限額シミュレーター: 季節需要は高いが、2026年10月改正の詳細（上限・時期）が検索で確定できず、既存の無料シミュレーターが多い（暫定 差別化2, 合計19）。バックログ保持。
- インボイス請求書ジェネレーター: PDF日本語フォント同梱が重く、今回は見送り（暫定 19）。

## 画面
単一ページ: 明細入力フォーム / 操作パネル（端数処理・CSV・JSON） / 結果表（明細・期間別集計） / 控除割合早見表 / 免責事項。

## データモデル
`Purchase { id, date(YYYY-MM-DD), supplier, amountYen(税込・整数), taxRate(10|8), supplierType(qualified|unqualified) }`
`AppState { version:1, rounding(floor|round|ceil), purchases[] }`

## 計算
- 含まれる消費税額 = 税込 × 税率/(100+税率)、端数処理は選択式（既定: 切り捨て）
- 控除割合: 適格→100%、免税等→仕入日の経過措置割合（`src/schedule.ts`）。控除額は円未満切り捨て
- 改正前スケジュール（〜2026/9: 80%、〜2029/9: 50%、以降0%）との差額を参考表示

## MVPに含まない
簡易課税・2割特例の計算、1億円超の取引に関する上限判定、PDF出力、有料版・ライセンス認証。
