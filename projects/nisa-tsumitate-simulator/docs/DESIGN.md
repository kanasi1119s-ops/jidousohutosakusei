# 設計

## スコアリング（2026-11-05）
| 観点 | 点 | 理由 |
|---|---|---|
| 需要 | 4 | 新NISAは継続的な検索需要。2026年度税制改正（つみたて投資枠の対象年齢撤廃、2027年1月〜）で話題 |
| 実装難易度 | 5 | 計算ロジックのみ |
| 法的リスクの低さ | 4 | 投資情報のため免責・非勧誘の明記が必須 |
| 差別化 | 3 | 既存サイトは多いが「登録不要・オフライン・CSV/JSON出力・生涯枠打ち切り反映」で差別化 |
| 運用コストの低さ | 5 | 静的ホスティングのみ |
| **合計** | **21/25** | 採用（18点以上） |

サイト形態: **W1**（サーバー処理不要のため）。

## 要件（MVP）
- 入力: 初期投資額（成長枠）、つみたて枠月額、成長枠月額、想定年利、運用年数
- 出力: 累計元本、評価額、運用益、課税口座(20.315%)との税額差、年次表
- 年間枠(120万/240万)超過はエラー、生涯枠(1,800万/成長1,200万)到達で積立打ち切り＋注意表示
- JSON設定の入出力、CSV出力(BOM付きUTF-8)、localStorage保存、PWA、CSPで外部通信ゼロ

## 含まない
商品別手数料、為替、インフレ、取り崩し、18歳未満枠、PDF出力、有料版

## 計算モデル
月利 = (1+年利)^(1/12)-1。月初に積立→月末に月利を反映。税額差 = floor(運用益×0.20315)。

単一ページ: 入力フォーム / 結果カード / 年次表 / 免責
