# 設計

- コンセプト: 積立額・利回り・期間から資産額と非課税枠の使用状況を試算する、登録不要・オフラインのNISAシミュレーター
- ターゲット: 新NISAで積立を始めたい／続けている個人、こどもNISA（2027年1月開始予定）を検討する保護者
- サイト形態: **W1**（計算のみでサーバー不要、静的ホスティング可）
- 収益化仮説（検証前の仮説）: 広告・アフィリエイト（証券口座開設等。表記ルール要確認）、買い切り有料版（複数シナリオ比較・PDF出力）
- MVP含む: 成人/こども切替、一括＋つみたて枠＋成長枠の月次複利試算、総枠・成長枠の頭打ち、課税口座（20.315%）との比較、年次表、SVGグラフ、JSON/CSV入出力、PWA
- MVP含まない: 手数料・インフレ・為替・取り崩し・枠の再利用（売却による復活）・有料版

## スコアリング（22/25）
需要4（新NISA・2027年こどもNISAで話題）/ 実装難易度5 / 法的リスク4（投資助言に該当しない表現・免責が必須）/ 差別化3（既存の公式・金融機関のシミュレーターは多い。こどもNISA対応・登録不要・オフラインで差別化）/ 運用コスト5 = 22。

## 却下・見送り
- ふるさと納税上限額（前サイクルの年収の壁と導線が重複、スコア再計算が必要）: 見送り
- 請求書ジェネレーター（インボイス制度の経過措置の確認コストが高い）: 次回以降
- スクレイピング型比較サイト: 法務リスクで却下（継続）

## 画面: 単一ページ（入力フォーム／結果サマリ／非課税枠バー／グラフ／年次表／免責）
## データモデル: `SimInput {account, initialYen, monthlyTsumitateYen, monthlyGrowthYen, annualReturnPct, years}`
## 計算仮定: 月次複利（月利=(1+年利)^(1/12)-1）、月初に拠出、総枠・成長枠到達後は拠出停止
