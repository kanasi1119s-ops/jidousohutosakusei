# 設計書

## 企画（PdM）
- コンセプト: 「登録不要・オフライン・入力が外に出ない」新NISA積立シミュレーター
- ターゲット: 新NISAを始めたい/始めたばかりの個人、家計の長期計画を立てたい人
- サイト形態: **W1**（計算のみでサーバー不要。運用コスト最小）
- 収益化仮説（保証なし）: 広告・アフィリエイト（証券会社比較への導線）、将来の買い切り有料版（複数シナリオ保存・PDF出力）

### スコアリング（25点満点）
| 観点 | 点 | 理由 |
|---|---|---|
| 需要 | 4 | 新NISAは継続的に検索需要が高い。年末は来年の積立設定の検討時期 |
| 実装難易度 | 5 | 計算ロジックのみで1サイクル内に完成可能 |
| 法的リスク | 4 | 投資助言に見えない表現・免責が必須。個人情報なし |
| 差別化 | 3 | 既存サイトは多いが「枠上限の自動反映・課税口座差・実質価値・逆算」を登録不要で提供 |
| 運用コスト | 5 | 静的ホスティングのみ |
| **合計** | **21** | 採用 |

### 却下・保留案
- ふるさと納税上限額シミュレーター: 時期的需要は高いが、2026年分の控除額改正（基礎控除・給与所得控除）の一次情報の確認が取れず、誤った上限額表示のリスク（金銭的損害）があるため今回は保留（スコア: 需要5/難易度3/法務3/差別化2/運用5=18、確認後に再評価）。
- 請求書ジェネレーター: 次サイクル候補（バックログ）。

### MVPスコープ
含む: 一括+毎月積立、年利、期間、インフレ、目標逆算、枠上限、課税口座比較、グラフ、年次表、JSON/CSV、PWA
含まない: 成長/つみたて枠の内訳、売却による枠復活、取崩しシミュレーション、複数シナリオ保存、PDF、有料版

## 計算仕様
- 月利 = (1+年利)^(1/12)-1。月初に積立→月末に運用益反映。開始時一括額は1年目の最初に投資
- NISA枠: 年間360万円（初回一括も含む）・生涯簿価1,800万円。超過分は**投資されない**ものとして除外し警告表示
- 課税口座手取り = 評価額 − max(0, 運用益)×20.315%（期末全額売却の目安）
- 実質価値 = 評価額 / (1+インフレ率)^年
- 目標逆算: 二分探索（探索上限は月30万円）

## 画面
単一ページ: 入力フォーム → 結果（KPI・警告・目標逆算・SVGグラフ・年次表）→ 免責
## データモデル
`SimulatorInput {initialYen, monthlyYen, annualReturnPct, years, inflationPct, goalYen}`（localStorage / JSON）
