# 設計

## 企画・スコアリング（Phase 0〜1）
- 調査: 2026年度税制改正大綱（2025年12月）で、2027年に18歳未満向けつみたて投資枠（こどもNISA）・売却枠の当年中復活が予定されるなど制度変更が続き検索需要が高い。
  参考: [金融庁 令和8年度税制改正](https://www.fsa.go.jp/news/r7/sonota/20251226-2/01.pdf)、[NRI](https://www.nri.com/jp/media/column/kiuchi/20251215_2.html)
- 採用: 新NISA積立シミュレーター（W1）。理由: 計算のみで完結、法的リスク小、静的ホスティングで運用費ほぼゼロ、「入力が端末から出ない」が差別化。
- スコア: 需要4 / 実装難易度5 / 法的リスク4 / 差別化3 / 運用コスト5 = **21/25**
- 却下: インボイス請求書ジェネレーター（PDF出力・制度確認が重く次サイクル）19/25、スクレイピング型比較サイト（法務）
- 収益化仮説: 広告・アフィリエイト（証券会社口座開設は要規約確認）、買い切り有料版（複数シナリオ比較）。保証なし。

## 要件（MVP）
含む: 上記機能一覧。含まない: 売却・枠復活、18歳未満枠、インフレ・手数料・為替、複数シナリオ保存、有料版。

## 計算モデル
月初拠出・月末運用益。月利=(1+年利)^(1/12)-1。年間枠・生涯枠を超える分は投資しない。初期投資は1年目1月に成長投資枠へ。
課税口座は同額拠出・同利回りで最終年に全売却し、利益×20.315%を課税と仮定。
