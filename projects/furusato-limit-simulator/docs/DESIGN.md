# 設計書

## コンセプト
「ふるさと納税の上限額を、登録なし・データ送信なしで試算し、寄附の残り枠まで管理できる」W1（静的・ブラウザ完結）サイト。

## サイト形態: W1
サーバー処理は不要（計算と保存はすべてブラウザ内）。運用コストはほぼゼロで、GitHub Pages / Cloudflare Pages 等の静的ホスティングで配信可能。

## プロジェクト選定スコア: 20/25
| 観点 | 点 | 根拠 |
|---|---|---|
| 需要 | 5 | 寄附期限（12月31日）前の11〜12月は検索需要が最大化する季節イベント。2026年10月に返礼品の経費割合上限引き下げ等の制度変更が始まった（検索結果ベース） |
| 実装難易度 | 3 | 所得税・住民税の計算が必要だが、1サイクルでMVP可能 |
| 法的リスクの低さ | 4 | 計算のみ。返礼品データ・スクレイピングは扱わない。税務助言とならない免責が必要 |
| 差別化 | 3 | 競合は多い（大手ポータルのシミュレーター）。差別化軸は「登録不要・外部送信なし・オフライン」「令和8年分の所得税控除（基礎控除104万円等）の反映」「残り枠・ワンストップ管理」 |
| 運用コストの低さ | 5 | 静的サイト |

## 却下・保留案
- スクレイピング型の返礼品比較サイト: 各ポータルの規約・著作権リスクが高く、法務スコアが低いため却下
- インボイス請求書ジェネレーター: 有力（バックログ継続）。今回は季節需要を優先
- 年収の壁シミュレーターのしきい値更新: 継続タスクとして別途バックログ（本サイクルでは新規優先）

## MVPスコープ
含む: 上限額試算（給与所得者、配偶者・扶養・その他控除・住宅ローン控除）、調整控除、寄附の記録、残り枠、5自治体超の警告、CSV/JSON、PWA
含まない: ふるさと納税の事業所得・年金・株式配当等、医療費控除の自動計算、返礼品検索、有料版

## 画面
単一ページ: ①入力フォーム ②試算結果（目安・余裕を見た目安・内訳） ③寄附の記録（追加・一覧・削除・出力）

## データモデル（localStorage キー `furusato-limit-simulator:data:v1`）
`{ version: 1, input: LimitInput, donations: Donation[] }`（`src/calc.ts`, `src/donations.ts` 参照）

## 計算式（`src/calc.ts`）
1. 給与所得 = 給与収入 − 給与所得控除（所得税用と住民税用で最低保障額が異なる）
2. 課税所得（所得税）= 給与所得 − 社保 − 基礎控除(令和8年分: 合計所得489万円以下104万円) − 配偶者/扶養 − その他
3. 課税所得（住民税）= 同様（基礎控除43万円等の住民税の人的控除）
4. 住民税所得割 = 課税所得×10% − 調整控除 − 住宅ローン控除（住民税分）
5. 上限額 = 所得割×20% ÷ (90% − 所得税率×1.021) + 2,000円（1,000円未満切り捨て）。余裕目安は90%

## 既知の近似・仮定（要確認）
- 給与所得控除の令和8〜9年分の特例（最低保障74万円等）の適用範囲を「給与収入190万円以下」と仮定
- 調整控除の人的控除差（基礎5万円等）は据え置きと仮定
- 住民税の税率は一律10%（均等割・森林環境税は上限額に影響しないため考慮しない）
- 特定親族特別控除、年収2,350万円超の基礎控除逓減は簡易化
- 令和9年（2027年）寄附分以降の高所得者向け特例控除の上限は未反映（2026年寄附には適用されない）
