# 設計書

## 企画サマリ
- コンセプト: 「登録不要・入力がブラウザから出ない」ふるさと納税の控除上限額シミュレーター。年末（寄附期限 2026-12-31）に向けた需要を想定。
- ターゲット: 給与所得者（会社員・パート）で、年末に寄附額を調整したい人。
- サイト形態: **W1（静的・ブラウザ完結）**。理由: 計算のみで完結し、サーバー・会員管理が不要。
- 収益化仮説（保証なし）: 広告・アフィリエイト（要人間判断）、寄付。現MVPは無料版のみ。

## スコアリング（21/25）
| 観点 | 点 | 根拠 |
|---|---|---|
| 需要 | 5 | 年末の寄附期限（12/31）、ワンストップ期限（翌1/10）に向け検索需要が高まる季節要因 |
| 実装難易度 | 4 | 公開計算式があり計算ロジックは単純。ただし2025年税制改正（基礎控除・給与所得控除）の反映に注意 |
| 法的リスクの低さ | 4 | 外部データ取得なし。免責・一次情報の確認導線が必要 |
| 差別化 | 3 | 競合は多い。登録不要・オフライン・ブラウザ外送信ゼロ・寄附済み額の残り表示で差別化 |
| 運用コストの低さ | 5 | 静的サイト |

却下案: インボイス請求書ジェネレーター（20/25: 競合が非常に多く差別化が弱い。次候補）、スクレイピング型価格比較（法務リスク）。

## MVPスコープ
含む: 給与所得者の上限額目安、配偶者控除・一般/特定扶養、寄附済み額の残り、JSON/CSV入出力、PWA。
含まない: 配偶者特別控除、老人扶養、障害者控除、住宅ローン控除、医療費控除の自動計算、事業所得・配当、特定親族特別控除、複数パターン保存。
（未対応項目は控除が小さく＝上限が低めに出る安全側にするか、免責に明記）

## 計算式（src/calc.ts）
1. 給与所得 = 給与収入 − 給与所得控除（令和7年分以降、最低保障65万円）
2. 所得税課税所得 = 給与所得 − 社保 − その他控除 − 基礎控除(95/88/68/63/58万円の段階) − 配偶者 − 扶養（千円未満切捨て）
3. 住民税課税所得 = 同様に基礎控除43万円、配偶者33万円、扶養33万/45万円
4. 所得割額 = 課税所得×10% − 調整控除
5. 上限額 = 所得割額×20% ÷ (90% − 所得税率×1.021) + 2,000円（1,000円未満切捨て）
6. 「余裕をみた目安」= 上限額×0.9（本ツール独自の便宜的な目安）

妥当性確認: 公表されている目安表（年収300万/400万/500万/700万の独身: 約2.8万/4.2万/6.1万/10.8万円等）と一致することをユニットテスト／ベンチで確認。
