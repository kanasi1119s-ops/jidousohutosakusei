# 設計

## 企画（PdM）
- コンセプト: 年収と家族構成だけで、ふるさと納税の控除上限額の目安がすぐ分かる。登録不要・オフライン・入力データは端末から出ない。
- ターゲット: 年末（12/31期限）に寄附額を決めたい給与所得者。
- サイト形態: **W1**（サーバー処理不要のため）。
- 収益化仮説（保証なし）: 広告・アフィリエイトは外部通信ゼロ方針と衝突するため、寄付・スポンサー、または買い切り有料版（複数パターン保存・PDF出力）を仮説として検証。
- 市場調査メモ（2026-11-28、Web検索）: ポイント付与禁止（2025/10〜）、2026/10から自治体の指定基準厳格化、令和8年度改正（所得税の基礎控除・給与所得控除の最低保障額引上げ、2027年寄附分から特例控除額に193万円の定額上限）。年末は検索需要が増える季節要因。ただし寄附の前倒し傾向で年末集中は弱まるとの指摘あり。

## スコアリング（25点満点）
| 観点 | 点 | 根拠 |
|---|---|---|
| 需要 | 4 | 年末の季節需要。ただし大手ポータルの無料シミュレーターが多数存在 |
| 実装難易度 | 5 | 計算ロジックのみ |
| 法的リスクの低さ | 4 | 税額の一般的試算。免責・基準日・出典明記が必須 |
| 差別化 | 3 | 登録不要・オフライン・完全ローカル・早見表と寄附予定額の超過判定 |

| **合計** | **21** | 18点以上のため採用 |

却下案: スクレイピング型価格比較（法務リスク）、請求書ジェネレーター（次サイクル候補として保持）。

## MVPスコープ
含む: 給与収入・社保・配偶者・扶養・その他控除・住宅ローン控除（住民税分）入力、上限目安、余裕を見た目安(90%)、年収別早見表、寄附予定額判定、JSON/CSV。
含まない: 自営業・年金・複数所得、医療費控除等の詳細計算、有料版、ワンストップ可否判定、2027年以降の193万円上限。

## 算式（src/calc.ts）
1. 給与所得 = 給与収入 − 給与所得控除（最低65万円の2025年分以降の表）
2. 住民税課税所得 = 給与所得 − 社保 − その他控除 − 基礎控除43万 − 配偶者 − 扶養（1,000円未満切捨）
3. 所得税課税所得も同様（基礎控除は2026年分の目安値）。税率表から所得税率 r を決定
4. 住民税所得割額 = 課税所得×10% − 調整控除 − 住宅ローン控除(住民税分)
5. 上限 = 所得割額×20% ÷ (90% − r×1.021) + 2,000円（100円未満切捨）

### 簡略化・前提（要注意）
- 社保未入力時は給与収入の15%で概算。
- 調整控除の人的控除差は従来の差額（基礎5万/配偶者5万/一般扶養5万/特定18万/老人10万）を維持した目安。
- 所得税の基礎控除（2026年分）は報道・解説ベースの値で、一次情報で未確認（所得税率の区分判定にのみ影響）。このため年収500万円独身の結果（約5.7万円）は、従来型の一般的な早見表（約6.1万円）より低めに出る。低めに出る方向は寄附超過リスクが小さい側だが、**公開前に人間が一次情報で確認すること**。
- 住民税側の給与所得控除は最低65万円（2025年改正）で計算。2026年改正（69万円）の住民税への適用年度は未確認。
