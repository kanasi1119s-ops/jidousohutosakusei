# LP草稿

## キャッチコピー案
- 「登録なしで、ふるさと納税の上限額の目安がわかる。」
- 「入力した年収は、あなたのブラウザの外に出ません。」
- 「上限額だけじゃない。寄附の“残り枠”まで管理。」

## ファーストビュー
**ふるさと納税 上限額シミュレーター（令和8年分）**
年収・家族構成を入れるだけ。会員登録なし、入力データは外部送信なし、オフラインでも使えます。
[上限額を試算する]

## 特長（実装・確認済みのことのみ）
1. **登録不要・外部送信なし**: 入力はブラウザ内のみに保存。通信はCSPで技術的に禁止しています
2. **オフラインで動作**: 一度開けば、電波がなくても使えます（PWA）
3. **令和8年分の所得税控除（基礎控除104万円など）を反映**した試算
4. **寄附の記録と残り枠**: 寄附日・自治体・金額・ワンストップ送付状況を管理。5自治体超の警告つき
5. **CSV（Excelで文字化けしないBOM付きUTF-8）とJSONバックアップ**に対応

## 使い方
1. 給与収入・家族構成などを入力 → 2. 上限額の目安を確認（余裕を見た目安も表示）→ 3. 寄附するたびに記録 → 4. 残り枠を確認

## 料金
無料（現時点）。将来、有料版を検討する場合は別途案内します。

## 注意書き
本ツールは簡易試算であり、税務上の助言ではありません。実際の上限額は住民税決定通知書等でご確認ください。寄附は12月31日までに決済完了したものが対象です。
