# LP草稿

## キャッチコピー案
- 「年収を入れるだけ。ふるさと納税の上限額が、登録なしで3秒でわかる。」
- 「入力した数字は、あなたのブラウザの外に出ません。」

## 構成
**ヒーロー**: ふるさと納税 控除上限額シミュレーター ／ 年収と家族構成から「自己負担2,000円で済む寄付額の目安」を試算。

**特長**（すべて実装・確認済みの事実）
1. 登録不要 — 会員登録・メール入力なしですぐ使える
2. 入力データは外部送信なし — ブラウザ内のみで計算・保存（CSPで外部通信を遮断）
3. オフラインでも使える — 一度開けば通信なしでも動作
4. 設定をJSONで保存、結果をCSVで保存（Excelで文字化けしないBOM付きUTF-8）
5. スマホでもPCでも見やすいレイアウト

**使い方**: ①給与収入を入れる ②社会保険料（分かれば）・配偶者・扶養を選ぶ ③「試算する」

**ご注意**: 目安の試算です。住宅ローン控除・医療費控除などがある方、個人事業主・年金受給者の方は結果が変わります。寄付額は上限に余裕を持たせ、最終判断は自治体・税理士等にご確認ください。
