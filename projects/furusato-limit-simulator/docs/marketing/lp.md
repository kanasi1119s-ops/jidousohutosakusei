# LP草稿
## キャッチコピー案
- 「登録なしで、年末のふるさと納税の上限額を3分で目安チェック」
- 「年収も家族構成も、あなたのスマホの外には出ません」

## ヒーロー
年収と家族構成を入れるだけで、ふるさと納税の控除上限額の目安がわかります。会員登録は不要。入力した内容はこの端末のブラウザの中だけで計算・保存され、外部には送信されません。

## 特長
1. **登録不要・送信なし**: 給与などの情報をサーバーに預けません。
2. **オフラインでも使える**: 一度開けば電波がなくても計算できます。
3. **寄附済み額との差がひと目でわかる**: 年末の駆け込み前に「あといくら」を確認。
4. **データは自分で持ち運べる**: 設定のJSON保存、結果のCSV保存（Excelでも文字化けしにくいBOM付きUTF-8）。
5. **計算の中身を公開**: 給与所得・課税所得・調整控除後の住民税所得割額まで内訳を表示。

## 対応範囲（正直に）
給与所得者／配偶者控除／一般・特定扶養。住宅ローン控除・医療費控除・配偶者特別控除などは未対応です。目安であり、控除額を保証するものではありません。

## 年末メモ
寄附の期限は12月31日（決済日基準が一般的）。ワンストップ特例の申請書は翌1月10日必着が目安です。
