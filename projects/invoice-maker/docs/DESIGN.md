# 設計

## コンセプト
フリーランス・個人事業主向け。「登録不要・データがブラウザから出ない・オフラインOK」のインボイス対応請求書作成サイト。

## サイト形態
**W1（静的サイト/ブラウザ完結SPA+PWA）**。理由: 計算・文書生成のみでサーバー処理が不要。運用費ゼロで差別化（クラウド型SaaSは登録・月額が前提）。

## スコアリング（25点満点）
| 観点 | 点 | 根拠 |
|---|---|---|
| 需要 | 4 | インボイス制度定着、2割特例が2026年9月30日を含む課税期間で終了し請求書の見直し需要 |
| 実装難易度 | 4 | 計算ロジックと印刷CSSのみ。PDFライブラリ不要 |
| 法的リスクの低さ | 5 | 第三者データ・スクレイピングなし |
| 差別化 | 3 | 無料ツールは多数あるが、登録不要+完全オフライン+税率ごと端数処理の明示 |
| 運用コスト | 5 | 静的ホスティングのみ |
| **合計** | **21** | |

却下: NISA積立シミュレーター 17（競合多数で差別化2）、ふるさと納税上限 16（既存の年収の壁と収益モデル重複）、議事録AI整形 15（ブラウザ内AIは難度高）。

## MVPスコープ
含む: 発行者情報、請求書編集、明細（税率別）、税抜/税込、端数処理、源泉徴収、保存/複製/削除、印刷(PDF)、CSV、JSONバックアップ、PWA。
含まない: 見積書/領収書、複数通貨、メール送信、クラウド同期、有料版・ライセンス認証、電子署名。

## 画面
単一ページ: 発行者情報 / 請求書の内容 / 保存済み一覧 / プレビュー（=印刷対象）。

## データモデル
`src/model.ts` の Invoice / Line / Issuer。保存形式 `{version:1, issuer, invoices[]}`。インポートは `sanitize*` で型・長さ・範囲を強制。

## 計算（src/calc.ts）
税率ごとに明細金額を合計→1回だけ端数処理。税込入力は 税額=合計×r/(100+r)、税抜=合計−税額。源泉は税抜小計に対して算出（1円未満切り捨て）。
