# 設計

## 企画（PdM）
- **コンセプト**: 登録不要・オフライン・データが端末から出ない、インボイス対応の請求書作成サイト
- **ターゲット**: フリーランス・個人事業主・小規模事業者
- **サイト形態**: W1（静的サイト）。計算・表示・保存はすべてブラウザ内で完結でき、サーバー不要のため
- **収益化仮説（検証前の仮説）**: 広告なしの無料版＋将来の買い切り有料版（テンプレート・取引先台帳・複数請求書管理）／寄付。保証なし
- **選定スコア（25点満点）**: 需要4 / 実装難易度4 / 法的リスクの低さ4 / 差別化3 / 運用コスト5 = **20**（採用基準18以上）
- 却下・保留: NISA積立シミュレーター 18（競合多数・公的ツールあり、次点）/ ふるさと納税上限額 17（前回の年収の壁と収益モデル重複）/ 議事録整形（ブラウザ内AI）15（難易度高・複数サイクル要）

## MVPスコープ
含む: 発行者情報、請求先、明細（品名・数量・単位・単価・税率）、税抜/税込入力、端数処理選択、税率別集計、プレビュー、印刷PDF、CSV出力、JSON往復、PWA
含まない（次サイクル以降）: 複数請求書の履歴管理、取引先台帳、見積書・納品書、ロゴ/印影画像、有料版・ライセンス認証、電子帳簿保存法対応

## 画面
1画面（左: 入力フォーム / 右: 請求書プレビュー。スマホは縦積み）。印刷時はプレビューのみ。

## データモデル（`src/model.ts` Invoice, schema=1）
issuer{name, registrationNumber, address, contact} / clientName / honorific / number / issueDate / dueDate / subject /
priceMode(exclusive|inclusive) / rounding(floor|round|ceil) / items[{name, quantity, unit, unitPrice, taxRate(10|8|0)}] / bank / notes

## 計算ルール（`src/calc.ts`）
- 整数（円）演算のみ。明細金額 = 数量(小数3桁まで) × 単価 を端数処理して整数化
- 消費税額 = 税率ごとの合計に対し **1枚の請求書につき税率ごとに1回** 端数処理（国税庁 インボイスQ&A 問57）。
  税抜: 合計×税率 / 税込: 合計×税率/(100+税率)
- 負数（値引き）は絶対値で端数処理して符号を戻す（仕様上の取り決め。税務判断は専門家へ）
- 入力範囲: 数量 ±10,000、単価 ±100,000,000円（整数精度保持のため）
