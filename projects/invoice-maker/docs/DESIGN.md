# 設計

## コンセプト / ターゲット
個人事業主・フリーランス・小規模事業者が、登録不要で、データを端末外に出さずに適格請求書を作れるサイト。月に数枚程度の発行を想定。

## サイト形態: W1
サーバー側処理が不要（計算・保存・出力すべてブラウザ内）のためW1。運用コストはほぼゼロ。

## スコアリング（20/25、採用基準18以上）
需要5（2割特例終了期でインボイス関心が高い）/ 実装難易度3 / 法的リスク4（税務情報のため免責必須）/ 差別化3（登録不要・オフライン・外部送信なし）/ 運用コスト5。

## 画面
請求書作成（フォーム+プレビュー）/ 保存済み / 設定 / データ（バックアップ）

## データモデル
Settings（発行者情報・端数処理・採番）と Invoice（宛名・日付・明細[品名,数量,税抜単価,税率]・源泉徴収・備考）。`src/model.ts`。読み込み/インポート時は全フィールドをサニタイズ。

## 計算仕様（`src/calc.ts`）
- 行金額 = 単価 × 数量（整数演算で端数処理）
- 消費税 = 税率ごとの税抜合計 × 税率 を1回だけ端数処理（適格請求書の端数処理ルール）
- 源泉徴収 = 税抜合計に対し 10.21%（100万円超の部分は20.42%）、1円未満切捨て
- 税抜合計の絶対値上限100億円（整数演算を安全整数内に保つため）

## MVPに含まない
見積書/納品書、取引先マスタ、PDF直接生成、有料版・ライセンス認証、電子帳簿保存法の要件対応、複数ユーザー。
