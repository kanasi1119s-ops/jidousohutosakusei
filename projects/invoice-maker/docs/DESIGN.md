# 設計

## 企画
- **コンセプト**: 登録不要・オフラインで使える、インボイス対応の請求書／見積書メーカー
- **ターゲット**: フリーランス・個人事業主・小規模事業者（クラウド会計に登録せず1枚だけ作りたい人）
- **サイト形態**: W1（サーバー処理が不要のため）
- **収益化仮説**（保証なし）: 無料公開＋寄付、将来的に買い切りの拡張版（複数書類管理・ロゴ・テンプレ）

## スコアリング（2026-10-21、25点満点）
| 観点 | 点 | 根拠 |
|---|---|---|
| 需要 | 4 | 2026年9月末で2割特例が終了、10月から経過措置の控除割合が70%へ変更。請求書の記載事項への関心が継続 |
| 実装難易度 | 4 | 計算ロジックと印刷CSSのみで完結 |
| 法的リスクの低さ | 4 | 第三者データ不使用。税務上の適否は保証しない旨を明記 |
| 差別化 | 3 | 無料・登録不要・オフラインの組合せ。ただし買い切りの類似HTMLツールが存在 |
| 運用コストの低さ | 5 | 静的ホスティングのみ |
| **合計** | **20** | 採用基準18点以上 |

## 却下・保留
- 年収の壁シミュレーターの継続（しきい値更新）: 一次情報URLの確認が人間作業のため、新規を優先しバックログ継続
- ふるさと納税上限額: 既存プロジェクトと領域が近く、スコア再計算が必要なため保留

## MVPスコープ
含む: 請求書／見積書、明細（数量・単価・税率10%/8%）、税抜／税込入力、端数処理選択、税率ごとの税額、登録番号の形式検査、印刷／PDF保存、JSON/CSV入出力、localStorage保存、PWA
含まない: 複数書類の一覧管理、ロゴ・押印画像、源泉徴収税、PDF直接生成、有料版・ライセンス認証

## 計算仕様
- 明細金額 = 数量 × 単価 を選択した端数処理で円単位に丸める
- 税額は「税率ごとの合計」から**1書類・1税率につき1回**だけ端数処理（適格請求書の要件に沿う）
- 税込入力時は 税額 = 合計 × r / (100 + r)

## 画面
単一ページ: 入力フォーム（書類情報／発行者／宛名／明細／振込先・備考）＋プレビュー（印刷時はプレビューのみ表示）

## データモデル
`InvoiceDoc`（src/calc.ts）を localStorage に `invoice-maker:docs:v1` として保存。
