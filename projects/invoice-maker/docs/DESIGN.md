# 設計

## 要件（MVP）
- 適格請求書の記載事項（発行者名・登録番号・取引年月日・取引内容・軽減税率対象の明示・税率ごとの対価と税額・請求先名）を満たすレイアウト
- 端数処理は1請求書・税率ごとに1回（国税庁 インボイスQ&A 問57 の取扱い）
- 外部通信ゼロ、オフライン動作、バックアップ手段

## 画面
単一ページ: 入力フォーム / 保存一覧 / プレビュー(印刷対象)。印刷時は `.screen-only` を非表示。

## データモデル
`src/model.ts` の `Invoice`（items: 品名・数量・単価・税率）。保存形式は `{app:"invoice-maker",version:1,invoices:[...]}`。

## 含まない（将来）
源泉徴収税、値引き行、非課税/不課税、複数通貨、テンプレート/ロゴ画像、見積書・領収書。
