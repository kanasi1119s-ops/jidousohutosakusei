# SNS告知文（草稿・コピペ用）

**パターンA（機能訴求）**
インボイス対応の請求書を、登録なしで作れるツールを作りました。
・10%/8%/非課税 ・源泉徴収 ・PDF保存 ・CSV出力
入力データはブラウザの外に出ません。オフラインでも動きます。
#インボイス #個人事業主 #フリーランス

**パターン B（悩み訴求）**
「請求書のためだけにアカウントを作りたくない」
そんな人向けに、開いてすぐ使える請求書メーカーを用意しました。取引先の情報は端末の中だけに保存されます。

**パターンC（制度の話題）**
2026年10月から、免税事業者等からの仕入の経過措置は80%→70%に。
請求書の記載事項（登録番号・税率ごとの税額）を、入力するだけで整えられる無料ツールです。
※税務上の最終確認はご自身で。
