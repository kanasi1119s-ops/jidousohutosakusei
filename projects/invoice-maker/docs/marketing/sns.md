# SNS告知文（草稿）

**A（機能）** 会員登録なしで使える請求書メーカーを作りました。インボイスの記載事項（登録番号・税率別の消費税）に対応、PDF保存もOK。データはブラウザの外に出ません。 #インボイス #フリーランス #個人事業主

**B（プライバシー）** 請求書ツールに取引先名や金額を預けたくない人向け。入力内容はこのブラウザの中だけに保存され、オフラインでも動きます。登録不要です。

**C（便利さ）** 月に1〜2枚の請求書のためにアカウントを作るのは面倒…という方へ。開いて、入力して、印刷→PDF保存。連番の採番や複製、源泉徴収の計算にも対応しています。
※ 税務上の最終確認はご自身でお願いします。
