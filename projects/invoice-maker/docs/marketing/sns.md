# SNS告知文草稿
**A（機能訴求）**
登録不要で使える請求書メーカーを作りました。インボイスの記載事項に沿った項目、税率ごとの消費税計算、源泉徴収の差引表示に対応。印刷→PDF保存もOK。入力内容はブラウザの外に出ません。 #請求書 #インボイス #個人事業主

**B（プライバシー訴求）**
「請求書の宛先や金額をクラウドに預けたくない」人向けに、ブラウザ内だけで完結する請求書ツールを作りました。オフラインでも動きます。 #フリーランス

**C（時短訴求）**
全角数字でも、カンマ付きでもOK。明細を入れるだけで税率別の合計が自動計算。CSV(Excel対応)とJSONバックアップも出せます。 #請求書作成
※記載内容は税務上の助言ではありません。制度の詳細は国税庁の情報をご確認ください。
