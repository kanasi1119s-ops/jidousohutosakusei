# SNS告知文（草稿）
**A（機能訴求）**
登録不要でインボイス対応の請求書がつくれる「請求書メーカー」を作りました。税率ごとの消費税計算、PDF保存、CSV/JSONバックアップに対応。入力データはブラウザの外に出ません。 #個人事業主 #フリーランス #インボイス

**B（プライバシー訴求）**
取引先の名前や金額を、クラウドに預けたくない人へ。ブラウザの中だけで動く請求書作成ツールです。一度開けばオフラインでも使えます。

**C（悩み訴求）**
「消費税の端数、明細ごとに丸めてない？」インボイスでは1枚の請求書につき税率ごとに1回の端数処理です。そのルールで自動計算する無料ツールを作りました。（※個別の判断は税理士等へ）
