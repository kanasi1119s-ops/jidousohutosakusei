# SNS告知文（草稿）
1. 会員登録なしで作れるインボイス対応の請求書メーカーを作りました。入力したデータはブラウザの外に出ません。オフラインでも動きます。消費税は税率ごとに1回の端数処理。PDF保存はブラウザの印刷から。 #インボイス #フリーランス #個人事業主
2. 請求書、毎月どうしてますか？ 開いてすぐ作れて、データはPCの中だけ。源泉徴収や軽減税率にも対応した無料ツールです。※税務判断は国税庁情報・税理士でご確認を。
3. 【開発メモ】消費税の端数処理は「明細ごと」ではなく「1枚の請求書で税率ごとに1回」。国税庁Q&Aの例（税込60,000円/40,000円→5,454円/2,962円）をテストで検証しています。
