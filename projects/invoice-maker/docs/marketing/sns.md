# SNS告知文（草稿）

**パターンA（プライバシー訴求）**
登録なしで使える、インボイス対応の請求書メーカーを作りました。入力した内容はブラウザの外に出ません。オフラインでも動きます。税率ごとの端数処理にも対応。 #インボイス #フリーランス #個人事業主

**パターンB（端数処理訴求）**
請求書の消費税、「行ごと」に端数処理していませんか？インボイス制度では税率ごとの合計に対して1回。そこをちゃんと計算する請求書メーカーです。ブラウザだけで使えます。 #インボイス制度 #請求書

**パターンC（実務訴求）**
登録番号の形式・発行日・請求先など、適格請求書の記載事項の入力漏れを画面でチェック。保存・複製（番号が自動で進む）・CSV／PDF出力まで、ブラウザ完結。 #請求書作成 #確定申告準備

※いずれも公開URL確定後に追記。税務上の保証をうたう表現は使わないこと。
