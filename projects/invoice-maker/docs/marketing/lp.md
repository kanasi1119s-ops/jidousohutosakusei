# LP草稿

## キャッチコピー案
- 「登録なしで、1枚だけ。インボイス対応の請求書をブラウザで。」
- 「入力した内容は、あなたのブラウザの外に出ません。」

## 特長（実装・確認済みの事実のみ）
1. **登録不要**: アカウント作成なしで使えます
2. **データは端末内に保存**: 外部サーバーへ送信しません（外部通信はCSPで遮断）
3. **オフライン対応**: 一度開けば通信なしでも作成できます（PWA）
4. **税率ごとの消費税額**: 10%／8%（軽減）を分けて集計し、税率ごとに1回だけ端数処理
5. **登録番号欄**: T+13桁の形式チェック付き
6. **印刷／PDF保存**: ブラウザの印刷機能でPDFにできます
7. **バックアップ**: JSON／CSVで入出力

## 料金案
現時点は無料。将来の拡張版（複数書類の管理など）は買い切りを検討（未実装・価格未定）。

本ツールは書類作成の補助であり、税務上の適否を保証するものではありません。
