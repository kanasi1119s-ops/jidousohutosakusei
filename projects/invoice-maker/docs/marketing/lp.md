# LP草稿

## キャッチコピー案
- 「登録なしで、今すぐ請求書。入力した内容は、あなたのブラウザの外に出ません。」
- 「インボイスの記載事項に沿った請求書を、オフラインでも。」

## 特長（実装・確認済みのもののみ）
1. **登録不要・外部送信なし**: 入力データはこのブラウザ内にだけ保存されます。
2. **インボイスの記載項目に対応した書式**: 登録番号、取引年月日、税率ごとの税抜合計と消費税額、軽減税率の対象表示。
3. **10%・8%（軽減）を混在可**: 端数処理は税率ごとに1回。切り捨て/四捨五入/切り上げを選べます。
4. **オフラインでも動作**: 一度開けばネットがなくても使えます。
5. **PDF保存・印刷、CSV・JSONで書き出し**。

## 料金プラン案（仮説・未提供）
- 無料: 現在の全機能
- 買い切り有料版（検討中）: 複数テンプレート、取引先の保存 など

## 注意書き
書式作成の補助ツールです。適格請求書の要件・税額・登録状況は国税庁の公表情報や税理士等でご確認ください。
