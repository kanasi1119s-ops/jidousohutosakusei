# 商品説明文案（BOOTH / Gumroad 等・有料版またはサポート版を出す場合の下書き）

**インボイス対応 請求書メーカー（ブラウザ版）**

登録不要・オフライン対応の請求書作成ツールです。入力したデータはお使いのブラウザ内にのみ保存され、外部に送信されません。

【できること】
- 税率別（10%・8%軽減・非課税）の自動計算、端数処理の選択
- 税抜／税込どちらの入力にも対応
- 源泉徴収税額の差し引き表示
- 適格請求書の記載事項チェック（入力漏れの目安）
- 請求書の複数保存・複製、JSONバックアップ、CSV書き出し
- ブラウザの印刷機能でPDF保存

【ご注意】
- 本ツールは作成補助であり、税務・法律上の助言ではありません。
- 簡易インボイス・電子インボイス（Peppol）には対応していません。
- データはブラウザ内に保存されます。端末の変更やブラウザデータの消去で失われるため、バックアップをお取りください。

※ 価格・提供形態・特定商取引法に基づく表記は、人間が決定・記入してください。
