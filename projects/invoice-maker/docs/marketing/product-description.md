# 商品説明文案（BOOTH / Gumroad 等。現時点は無料公開前提、有料化する場合の叩き台）

**インボイス対応 請求書メーカー（ブラウザ版）**

登録不要・オフライン対応の請求書作成ツールです。税率（10%／8%／非課税）ごとの合計に対して消費税を1回だけ端数処理し、適格請求書の主な記載事項の入力漏れを確認できます。入力データはブラウザの外へ送信されません。

【できること】
- 請求書の作成・保存・複製・削除／印刷・PDF保存
- 税抜／税込入力、端数処理の選択、源泉徴収の計算
- CSV（BOM付きUTF-8）・JSONバックアップの書き出しと読み込み

【ご注意】
- 計算結果は一般的な目安です。税務上の判断は専門家にご確認ください。
- 保存先はお使いのブラウザ内です。定期的にバックアップを書き出してください。
