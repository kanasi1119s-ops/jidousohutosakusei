# invoice-maker（インボイス対応 請求書メーカー）

登録不要・オフライン対応の請求書作成Webサイトです。**サイト形態: W1（静的サイト／ブラウザ完結）**。
入力データはブラウザの `localStorage` にのみ保存され、外部へ送信されません（CSPで外部通信を禁止）。

## 機能
- 発行者情報（氏名・登録番号T+13桁・住所・振込先）の保存
- 税率ごと（10% / 8%軽減）に1回だけ端数処理する消費税計算（税抜入力／税込入力、切捨て・四捨五入・切上げ）
- 請求書プレビュー＝印刷対象（ブラウザの「PDFに保存」でPDF化）。軽減税率対象に「※」表示
- 請求書の保存・編集・複製・削除、一覧のCSV出力（BOM付きUTF-8）、全データのJSONバックアップ／復元
- PWA（一度開けばオフラインでも動作）、スマホ幅〜PC幅のレスポンシブ

## 開発
```
npm install
npm run dev          # 開発サーバー
npm run check        # 型チェック + ユニットテスト
npm run build        # dist/ に静的ファイル一式を生成（相対パス: サブディレクトリ配置可）
npm run test:e2e     # Playwright E2E（初回は npx playwright install chromium）
```

## データの保存場所
ブラウザの `localStorage`（キー `invoice-maker:v1`）。ブラウザのデータ消去で失われるため、定期的に「バックアップ(JSON)」を保存してください。
