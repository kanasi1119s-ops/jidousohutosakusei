# invoice-maker（適格請求書ジェネレーター）

登録不要・オフライン対応の、ブラウザ完結型 適格請求書（インボイス）作成ツール（サイト形態: **W1 静的サイト/PWA**）。

- 税率ごと（10% / 8% / 非課税）に区分して消費税を1請求書につき1回だけ端数処理（切り捨て/四捨五入/切り上げ）
- 登録番号（T+13桁）の形式チェック、必須記載事項の不足警告
- 「PDFとして保存／印刷」（ブラウザの印刷機能を利用。外部ライブラリ不使用）
- 明細CSV（BOM付きUTF-8）、全件JSONバックアップ/復元
- 外部通信ゼロ（CSPで担保）、PWAとしてオフライン動作

## データの保存場所
ブラウザの localStorage のみ。サーバーには送信されません。端末・ブラウザを変える際は「全件をJSONでバックアップ」を使ってください。

## 開発
```
npm ci
npm run dev        # 開発サーバー
npm run check      # 型チェック
npm test           # ユニットテスト(Vitest)
npm run build      # dist/ に静的ファイルを出力（相対パス）
npm run test:e2e   # E2E(Playwright。初回は npx playwright install chromium)
```

## 免責
請求書作成の補助ツールであり、税務・法律上の助言ではありません。詳細は `docs/LEGAL.md`。
