# 請求書メーカー（invoice-maker）

インボイス（適格請求書）の記載事項に沿った請求書を、**登録不要・ブラウザ完結・オフライン対応**で作成できる静的Webサイトです。

- サイト形態: **W1（静的サイト／ブラウザ完結・PWA）**。サーバー不要。
- 入力データの保存場所: **利用者のブラウザの `localStorage`** のみ（外部送信なし。CSPで外部通信も遮断）。
- バックアップ: JSON書き出し/読み込み、明細のCSV出力（BOM付きUTF-8、Excelで文字化けしない）。
- PDF: ブラウザの「印刷 → PDFとして保存」を使用（外部ライブラリ不使用）。

## 主な機能
- 発行者情報（氏名・登録番号T+13桁の形式チェック・住所・振込先）
- 明細（数量・単価・税率10%/8%/非課税）、税率ごとに1回の端数処理（切り捨て/四捨五入/切り上げ）
- 源泉徴収税（10.21%、100万円超部分20.42%）の差引表示
- 全角数字・カンマ入力対応、A4印刷レイアウト、スマホ(375px)〜PC対応

## 開発
```bash
npm ci
npm run dev          # 開発サーバー
npm run check        # 型チェック
npm test             # ユニットテスト(Vitest)
npm run build        # 本番ビルド(dist/)
npm run test:e2e     # E2E(Playwright。初回は npx playwright install chromium)
```
ビルド成果物 `dist/` は相対パス(`base: './'`)なので、サブディレクトリ配置の静的ホスティングでも動作します。公開手順は `docs/RELEASE.md`。
