# 請求書メーカー（invoice-maker）

適格請求書（インボイス）の記載事項に対応した請求書を、**会員登録なし・ブラウザ完結・オフライン対応**で作成できる静的Webサイトです。

- サイト形態: **W1（静的サイト／ブラウザ完結PWA）**。サーバー不要
- 入力データはブラウザの localStorage にのみ保存。外部通信なし（CSPで担保）
- PDFはブラウザの「印刷 → PDFとして保存」を利用（外部ライブラリ不要）
- 本番依存パッケージ: 0（開発ツールのみ）

## 主な機能
- 発行者情報・登録番号（T+13桁の形式チェック）・振込先の保存
- 明細（数量は小数3桁まで、税率 10% / 8%軽減 / 非課税等）、税率ごとの合計と消費税（税率ごとに1回の端数処理。切捨て/四捨五入/切上げを選択）
- 源泉徴収（任意。税抜額に対し10.21%、100万円超の部分は20.42%）
- 請求書の保存・開く・複製・削除、連番の自動採番
- JSONバックアップの書き出し/復元、請求書一覧CSV（Excelで開ける BOM付きUTF-8）
- レスポンシブ（375px〜1280px以上）、PWA（オフライン動作）

## 開発
```bash
npm ci
npm run dev        # 開発サーバー
npm run check      # 型チェック
npm test           # ユニットテスト（Vitest）
npm run build      # dist/ に静的ファイルを出力
npx playwright install chromium   # 初回のみ
npm run test:e2e   # E2E（ビルド→プレビュー→Playwright）
```

## データの保存場所
ブラウザの localStorage（キー `invoice-maker:data:v1`）。端末・ブラウザを変える場合は「データ」タブでJSONバックアップを取得してください。
