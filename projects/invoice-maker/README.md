# invoice-maker（インボイス対応 請求書メーカー）

税率ごとの端数処理と適格請求書の記載事項チェックに対応した請求書を、**登録不要・オフライン対応・ブラウザ完結**で作成するWebサイトです。

- サイト形態: **W1（静的サイト／ブラウザ完結）**。サーバー不要
- 入力データはすべてブラウザ内（localStorage）に保存され、外部へ送信されません（CSPで外部通信を遮断）
- PWA対応: 一度開けばオフラインでも動作します

## 主な機能

- 発行者・請求先・明細（品名／数量／単価／税率 10%・8%（軽減）・非課税）の入力
- 税抜入力／税込（内税）入力の切替、消費税の端数処理（切り捨て・四捨五入・切り上げ）
- **税率ごとに区分した合計に対して請求書1枚につき1回だけ端数処理**（インボイス制度の要件に沿った計算）
- 源泉徴収（10.21%／100万円超過分20.42%）と差引請求額の表示
- 適格請求書の記載事項チェック（登録番号 `T` + 13桁の形式確認を含む）
- 請求書の保存・開く・複製（番号を自動で1つ進める）・削除
- 印刷／PDF保存（ブラウザの印刷機能を利用。PDFライブラリ不使用）
- CSVダウンロード（BOM付きUTF-8）、バックアップのJSON書き出し／読み込み

## 開発

```bash
npm ci
npm run dev          # 開発サーバー
npm run check        # 型チェック
npm test             # ユニットテスト (Vitest)
npm run build        # 型チェック + 静的ビルド (dist/)
npm run test:e2e     # E2E (Playwright。初回は `npx playwright install chromium`)
```

## データの保存場所

ブラウザの localStorage（キー接頭辞 `invoice-maker:v1:`）。ブラウザのサイトデータを消去すると失われるため、
画面の「バックアップ(JSON)を書き出す」で定期的にバックアップしてください。
