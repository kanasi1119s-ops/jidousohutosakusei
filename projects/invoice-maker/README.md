# 適格請求書メーカー（invoice-maker）

登録不要・オフライン対応の、ブラウザ完結型インボイス（適格請求書）作成ツールです。
フリーランス・個人事業主が、請求書を作ってPDF保存（ブラウザの印刷機能）／CSV出力できます。

- **サイト形態**: W1（静的サイト／ブラウザ完結・PWA）。サーバー不要。
- **データの保存場所**: ブラウザの `localStorage`（キー `invoice-maker:data:v1`）のみ。外部送信なし（CSPで担保）。
- **バックアップ**: 「全データをバックアップ(JSON)」で書き出し、「バックアップを読み込み」で復元できます。
- **文字コード**: すべてUTF-8。CSVはExcelで化けないようBOM付きUTF-8。ダウンロードファイル名は英数字のみ。

## 主な機能

- 発行者情報（氏名・住所・登録番号 T+13桁の形式チェック・振込先）の保存
- 明細入力（税率 10% / 軽減8% / 非課税、税抜・税込入力、全角数字OK）
- 適格請求書の税額計算（税率ごとに区分した合計に対し、端数処理を1請求書・税率ごとに1回）
- 源泉徴収税額の差し引き（報酬・料金等の 10.21% / 100万円超部分 20.42%）
- 請求書の保存・再編集・削除、CSV出力、JSONバックアップ
- 印刷時は請求書部分のみを出力（ブラウザの「PDFに保存」でPDF化）
- PWA（一度開けばオフラインでも動作）、スマホ幅〜PC幅のレスポンシブ

## 開発

```bash
npm ci            # 依存関係のインストール
npm run dev       # 開発サーバー
npm run check     # 型チェック
npm test          # ユニットテスト（Vitest）
npm run build     # 型チェック + 本番ビルド（dist/）
npm run preview   # ビルド結果の確認（http://127.0.0.1:4173）
npx playwright install chromium   # 初回のみ（E2E用ブラウザ）
npm run test:e2e  # E2Eテスト（Playwright。ビルド→プレビュー起動を自動で行う）
```

公開手順は `docs/RELEASE.md`、設計は `docs/DESIGN.md`、デバッグ記録は `docs/DEBUG_LOG.md` を参照してください。
