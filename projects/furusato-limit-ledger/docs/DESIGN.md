# 設計

## 企画（PdM）
- コンセプト: 登録不要・データが端末から出ない「ふるさと納税 上限額＆寄付台帳」
- ターゲット: 年末に駆け込みで寄付する給与所得者、ワンストップ特例の管理が面倒な人
- サイト形態: **W1**（計算と台帳のみでサーバー処理が不要。運用コストほぼゼロ）
- 収益化仮説（保証ではない）: 広告なしの無料版＋将来の買い切り版（複数年の履歴比較・PDF出力など）／寄付
- MVPに含まない: 返礼品検索・自治体データ取得（スクレイピング回避）、住宅ローン控除・事業所得、有料版

## スコアリング（21/25）
需要5 / 実装難易度4 / 法的リスク4 / 差別化3 / 運用コスト5

| 却下案 | 点 | 理由 |
|---|---|---|
| インボイス請求書ジェネレーター | 18 | 既存の無料サービスが多く差別化が弱い、PDF依存で実装重め |
| NISA積立シミュレーター | 17 | 競合が非常に多く、季節性が弱い |
| 価格比較（スクレイピング） | 却下 | 規約確認コスト・法務リスク |

季節需要（寄付期限 12/31、ワンストップ申請書 1/10 必着）が近いため本案を優先。

## 画面
単一ページ: ① 上限額試算 ② 寄付台帳 ③ データ保存・移行

## データモデル
`AppState { version:1, year, input: LimitInput, donations: Donation[] }`
`Donation { id, date(YYYY-MM-DD), municipality, amountYen, method('onestop'|'kakutei'), sent }`

## 計算（src/calc.ts）
- 給与所得控除: 2025年分以降（最低65万円）
- 所得税の基礎控除: 2025〜2026年分の合計所得別（95/88/68/63/58万…）
- 住民税の基礎控除: 43万円、調整控除あり
- 上限 = 住民税所得割×20% ÷ (90% − 所得税率×1.021) + 2,000円（1,000円未満切捨て）
- 総務省の目安表（独身・給与収入のみ）と 300/400/500/700万円で一致することをテストで確認
