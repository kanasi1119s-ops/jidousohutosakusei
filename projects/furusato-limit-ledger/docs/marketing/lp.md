# LP草稿: ふるさと納税 上限額＆寄付台帳

## キャッチコピー案
- 「寄付の上限、あといくら？」を登録なしで。
- 入力したデータは、あなたのブラウザから出ません。
- 年末の駆け込み前に、上限額とワンストップの期限をまとめて確認。

## 特長（実装・確認済みの事項のみ）
1. **登録不要・外部送信なし**: 入力内容はブラウザ内にのみ保存。外部通信はCSPで遮断しています。
2. **上限額の目安を即試算**: 給与収入・配偶者・扶養などから控除上限額の目安を表示（総務省の目安表の独身例と一致を確認）。
3. **寄付台帳**: 自治体・金額・方法・申請書の送付状況を一覧管理。上限までの残額を表示。
4. **ワンストップ特例の見落とし防止**: 5自治体を超えると警告、申請書の未送付数と1/10必着までの残日数を表示。
5. **オフラインでも動作**: 一度開けば通信なしで利用可能。
6. **バックアップ**: CSV（Excelで文字化けしないUTF-8 BOM付き）とJSONで保存・復元。

## ご利用上の注意
- 試算結果は目安です。住宅ローン控除・事業所得などは考慮していません。
- 税務上の助言ではありません。最終確認は自治体・税務署・税理士へ。
