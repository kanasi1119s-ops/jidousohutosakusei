# 商品説明文案（有料版を出す場合の BOOTH / Gumroad 用・未実装機能は含めないこと）

**【ブラウザで開くだけ】インボイス対応 請求書メーカー**

登録不要・オフライン対応。入力したデータは外部に送信されません。
請求書／見積書／納品書／領収書を作成し、印刷またはPDF保存できます。

■ できること
- 登録番号・取引年月日・税率別の消費税額（10%／8%）を含む書類の作成
- 税抜／税込入力、端数処理（切り捨て・四捨五入・切り上げ）の選択
- 書類の保存、バックアップ（JSON）、明細のCSV出力（Excelで文字化けしない形式）

■ ご注意
- 税務・法律上の助言ではありません。要件・税率・経過措置は国税庁の最新情報をご確認ください。
- 登録番号の存在確認、簡易インボイス専用書式、電子帳簿保存法への対応は行いません。
- データはお使いのブラウザ内に保存されます。定期的にバックアップを保存してください。
