# インボイス対応 請求書メーカー（invoice-maker-jp）

適格請求書（インボイス）の記載事項に沿った **請求書・見積書・納品書・領収書** を作成し、印刷／PDF保存できる、
**登録不要・オフライン対応・ブラウザ完結** のWebサイトです。入力データはブラウザの外へ送信されません。

- サイト形態: **W1（静的サイト／ブラウザ完結Webアプリ・PWA）**
- スタック: TypeScript + Vite（実行時の依存パッケージはゼロ）
- データの保存場所: ブラウザの `localStorage`（この端末のこのブラウザ内のみ）。
  バックアップは画面の「バックアップ（JSON）を保存」から取得できます。

## 主な機能

- 発行者情報（氏名／名称・登録番号 T+13桁・住所・連絡先）の保存
- 税率ごと（10% / 軽減8%）の対象額・消費税額の集計（端数処理は税率ごとに1回）
- 税抜入力／税込入力、端数処理（切り捨て／四捨五入／切り上げ）の選択
- 軽減税率の明細に「※」を表示
- 全角数字・カンマ区切りでの数値入力に対応
- 書類の保存・再編集・削除、番号の自動繰り上げ
- 明細CSV（BOM付きUTF-8）、全データのバックアップ／復元（JSON）
- 印刷用レイアウト（A4）。ブラウザの印刷ダイアログから「PDFに保存」できます
- PWA（一度開けばオフラインでも動作）。外部通信はCSPで遮断

## 開発

```bash
npm install
npm run dev         # 開発サーバー
npm run check       # 型チェック
npm test            # ユニットテスト（Vitest）
npm run build       # 型チェック + 本番ビルド（dist/）
npm run preview     # ビルド結果の確認
npx playwright install chromium   # 初回のみ
npm run test:e2e    # E2Eテスト（Playwright。ビルドとプレビュー起動を自動で行う）
```

Node.js 22 以上を想定しています。

## ディレクトリ

- `src/calc.ts` 金額計算（整数演算・税率別集計）／`src/invoice.ts` 書類モデルと検証
- `src/storage.ts` 保存・バックアップ／`src/csv.ts` CSV出力／`src/main.ts` 画面
- `docs/` 設計・デバッグログ・セキュリティ・法務・公開手順・マーケ素材
