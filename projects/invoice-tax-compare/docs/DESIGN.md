# 設計書: インボイス特例 納税額比較

## 企画（PdM）
- 1行コンセプト: インボイス特例の切替期に、個人事業者が「どの方式が有利か」を登録不要・オフラインで比較できるサイト
- ターゲット: 免税事業者からインボイス発行事業者になった個人事業主・フリーランス
- 背景（2026-10-23時点の調査）: 2割特例は令和8年9月30日を含む課税期間まで。個人事業者は令和8年分が最後。令和8年度税制改正大綱では令和9・10年分に個人事業者向け3割特例が示されている（二次情報。一次情報は国税庁サイトで要確認）。免税事業者等からの仕入控除の経過措置は2026年10月に引き下げ予定。
- サイト形態: **W1**（サーバー処理が不要なため）
- 収益化仮説（保証なし）: 広告・税理士紹介のアフィリエイト・買い切り有料版（複数事業区分や年次比較）

### 却下・保留した案
- NISA積立シミュレーター（バックログ維持）: 制度変更（令和8年度改正大綱）の確定状況が未確認のため今回は保留
- インボイス請求書ジェネレーター: 差別化・PDF出力コストが大きく次サイクル以降

## MVPスコープ
含む: 4方式の納税額比較、適格性判定（理由表示）、還付表示、JSON/CSV入出力、PWA
含まない: 複数事業区分の簡易課税、少額特例の判定、中間納付、法人、有料版・ライセンス認証

## 計算仕様（`src/calc.ts`）
- 国税7.8%・地方消費税22/78。課税標準額は税率ごとに千円未満切り捨て
- 売上国税 = floor((標準額10%×7.8% + 標準額8%×6.24%))
- 仕入国税 = 税込仕入×78/1100（10%）+ 税込仕入×6.24/108（8%）。免税事業者等からの仕入は控除割合（入力可、既定70%）を乗じる
- 本則 = 売上国税 − 控除。マイナスは還付。納付は100円未満切り捨て
- 簡易 = 売上国税 ×（1−みなし仕入率）。2割特例 = 売上国税×20%。3割特例 = 売上国税×30%
- 適格性: 2割特例=令和8年分・免税→登録・基準期間1,000万円以下 / 3割特例=令和9・10年分・同要件 / 簡易=基準期間5,000万円以下・届出済み
- 入力上限は4,999,999,999円（整数精度保証のため）

## 画面
単一ページ: 入力フォーム → 比較結果表（最小方式を強調）→ 免責事項。
