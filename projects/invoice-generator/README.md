# インボイス請求書ジェネレーター（invoice-generator）

インボイス制度（適格請求書）の記載事項に沿った請求書を作成し、印刷／PDF保存・CSV出力できる **ブラウザ完結の静的Webサイト（W1）** です。登録不要・入力データは外部送信なし・オフライン動作（PWA）。

## 主な機能
- 発行者情報（氏名・登録番号T+13桁・住所・振込先）と請求書の入力
- 明細ごとの税率（10% / 軽減8% / 0%）選択、税率ごとの区分合計と消費税額（端数処理は税率ごとに1回。切り捨て／四捨五入／切り上げ選択）
- 全角数字・カンマ入力に対応
- 発行前チェック（登録番号の形式・必須項目・金額上限・期限の前後）
- プレビュー＋「印刷／PDFとして保存」（ブラウザの印刷機能）
- 請求書の保存（ブラウザ内 localStorage）、全データのJSONバックアップ／復元
- 明細のCSV出力（BOM付きUTF-8、Excelで文字化けしない）

## データの保存場所
すべてこのブラウザの localStorage（キー `invoice-generator:data:v1`）。サーバーには送信しません（CSPで外部通信を禁止）。ブラウザのデータ削除で消えるため、JSONバックアップを推奨します。

## ローカル起動
```bash
npm ci
npm run dev        # 開発サーバー
npm run build      # 型チェック + 静的ビルド（dist/）
npm run preview    # ビルド結果の確認
```

## テスト
```bash
npm run check      # 型チェック
npm test           # ユニットテスト（Vitest）
npx playwright install chromium   # 初回のみ
npm run test:e2e   # E2E（Playwright、デスクトップ＋スマホ）
npm run verify     # 上記をまとめて実行
```

## 免責
本ツールは請求書作成の補助です。税務上の判断は国税庁の公表資料または税理士にご確認ください。公開手順は `docs/RELEASE.md` を参照。
