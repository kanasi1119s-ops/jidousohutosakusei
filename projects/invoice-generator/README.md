# 請求書ジェネレーター（invoice-generator）

インボイス制度（適格請求書）の記載事項に沿った請求書を、**登録不要・オフライン対応・入力データを外部送信しない**ブラウザ完結サイトで作成します。サイト形態は W1（静的サイト／PWA）です。

## 主な機能
- 発行者（登録番号 T+13桁の形式チェック付き）・請求先・件名・明細（数量/単価/税率 10%・8%・非課税）
- 税抜／税込入力、税率ごと1回の端数処理（切り捨て・四捨五入・切り上げ）、全角数字入力に対応
- 源泉徴収税額（10.21%、100万円超部分は20.42%）の簡易計算
- 印刷／PDF保存（ブラウザの印刷機能。印刷時はプレビューのみ表示）
- 請求書の保存・複製・削除、バックアップ（JSON）の書き出し／読み込み、一覧CSV（BOM付きUTF-8）
- PWA（一度開けばオフラインで動作）、スマホ幅〜PC幅のレスポンシブ

## データの保存場所
入力・保存した請求書は、**お使いのブラウザの localStorage にのみ**保存されます（サーバー送信なし。CSPで外部通信を遮断）。ブラウザのデータ消去で失われるため、バックアップ（JSON）を定期的に取得してください。

## 開発
```bash
npm ci
npm run dev            # 開発サーバー
npm run check          # 型チェック
npm test               # ユニットテスト（Vitest）
npm run build          # 静的ファイルを dist/ に出力
npm run test:e2e       # E2E（Playwright。初回は npx playwright install chromium）
```
公開手順は `docs/RELEASE.md`、設計は `docs/DESIGN.md`、法務・免責は `docs/LEGAL.md` を参照。
