# インボイス請求書ジェネレーター

適格請求書（インボイス）の記載事項に沿った請求書を作成し、印刷・PDF保存できる **W1（ブラウザ完結の静的サイト）** です。
登録不要・入力データはブラウザ外へ送信しない・オフラインでも動作します。

## 主な機能
- 発行者（登録番号 T+13桁の形式チェック）・宛先・明細（10% / 8%軽減税率）
- 消費税は **税率ごとに請求書1枚につき1回だけ** 端数処理（切捨て/四捨五入/切上げを選択）
- 源泉徴収税額（目安）の差し引き（任意）
- 印刷 / PDF保存（ブラウザの印刷機能。印刷時は入力欄を隠して請求書のみ出力）
- ブラウザ内保存（localStorage）、JSONバックアップのエクスポート/インポート、CSVダウンロード（BOM付きUTF-8）
- PWA（オフライン動作）、レスポンシブ（375px〜）、CSPで外部通信ゼロ

## 開発
```
npm ci
npm run dev        # 開発サーバー
npm run check      # 型チェック
npm test           # ユニットテスト（Vitest）
npm run build      # 静的ビルド（dist/）
npm run test:e2e   # E2E（Playwright。初回は npx playwright install chromium）
```

## データの保存場所
ブラウザの localStorage（キー `invoice-generator:v1`）のみ。サーバーへは送信されません。
ブラウザのデータ削除で消えるため、JSONバックアップを推奨します。
