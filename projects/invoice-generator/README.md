# インボイス請求書ジェネレーター（invoice-generator）

適格請求書（インボイス）の記載事項に沿った請求書を作成する、**ブラウザ完結・登録不要・オフライン対応**の静的Webサイトです（サイト形態: W1）。

- 入力データはこのブラウザの `localStorage` にのみ保存され、外部へ送信されません（CSPで外部通信を遮断）
- 税率ごと（10% / 8%軽減）に合計した対価に対して消費税を**1回だけ**端数処理（切り捨て/四捨五入/切り上げを選択）
- 登録番号（T+13桁）の形式チェック、全角数字入力の自動半角化
- 「印刷 / PDFとして保存」はブラウザの印刷機能を使用（外部ライブラリ・フォント不使用）
- CSV（BOM付きUTF-8、Excel対応）出力、JSONバックアップの保存・読み込み
- PWA対応、スマホ幅〜PC幅のレスポンシブ

## 開発

```bash
npm ci
npm run dev        # 開発サーバー
npm run check      # 型チェック
npm test           # ユニットテスト(Vitest)
npm run build      # 静的ファイルを dist/ に出力
npm run test:e2e   # E2E(Playwright。初回は npx playwright install chromium)
```

## データの保存場所
ブラウザの `localStorage`（キー `invoice-generator:v1`）。ブラウザのデータを消去すると失われるため、
「バックアップ(JSON)を保存」で定期的に保存してください。
