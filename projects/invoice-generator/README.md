# インボイス対応 請求書ジェネレーター

登録不要・オフライン対応の請求書作成Webサイト（W1: 静的サイト／ブラウザ完結PWA）。
入力データはブラウザ内（localStorage）にのみ保存され、外部へ送信されません。

## 主な機能
- 適格請求書の記載事項（発行者名・登録番号・取引年月日・取引内容・税率ごとの対価と消費税額・宛名）を満たす請求書の作成
- 10% / 8%（軽減）/ 非課税の混在対応。**消費税の端数処理は税率ごとに1回**（切り捨て・四捨五入・切り上げを選択）
- 税抜入力／税込入力の切替、値引き行（負の単価）、源泉徴収税額の差し引き（10.21%／100万円超の部分20.42%）
- 印刷 / PDF保存（ブラウザの印刷機能を使用。追加ライブラリなし）
- CSV出力（BOM付きUTF-8、Excelで文字化けしない）、全データのJSON書き出し／読み込み（バックアップ）
- PWA（一度開けばオフラインでも動作）、スマホ幅〜PC幅に対応

## 起動・テスト・ビルド
```bash
npm ci
npm run dev        # 開発サーバー
npm run check      # 型チェック
npm test           # ユニットテスト（Vitest）
npm run test:e2e   # E2E（Playwright。初回は npx playwright install chromium）
npm run build      # dist/ に静的ファイルを出力（相対パスなのでサブディレクトリ配置可）
npm run preview    # ビルド結果の確認
```

## データの保存場所
ブラウザの localStorage（キー: `invoice-generator:v1`）。ブラウザのサイトデータを消すと消えるため、
画面の「全データをJSONで書き出し」で定期的にバックアップしてください。
