# インボイス対応 請求書ジェネレーター

登録不要・オフライン対応のブラウザ完結型 請求書作成サイト（サイト形態: **W1 静的サイト／PWA**）。
入力データは端末のブラウザ内（localStorage）にのみ保存され、外部には送信されません。

## 主な機能
- 発行者情報（登録番号 T+13桁）・宛名・明細（10% / 8%軽減）の入力、全角数字・カンマ入力に対応
- 税率ごとに合計して消費税額を1回だけ端数処理（切り捨て / 四捨五入 / 切り上げ）、税抜・税込入力の切替
- 適格請求書の記載事項チェック（登録番号の形式、必須項目の不足を警告）
- 印刷 / PDF保存（ブラウザの印刷機能を使用）
- 請求書の保存・一覧・再編集・削除、JSONバックアップの書き出し/読み込み、一覧CSV（BOM付きUTF-8）

## セットアップ
```bash
npm ci
npm run dev        # 開発サーバー
npm run check      # 型チェック
npm test           # ユニットテスト（Vitest）
npm run build      # dist/ に静的ファイルを出力
npm run preview    # ビルド結果の確認
npm run test:e2e   # E2E（Playwright。初回は npx playwright install chromium）
```

## データの保存場所
ブラウザの localStorage（キー接頭辞 `invoice-generator:v1:`）。ブラウザのデータ削除・端末変更で失われるため、
画面の「バックアップ(JSON)」で定期的に保存してください。

## 免責
請求書作成の補助ツールであり、税務・法律上の助言ではありません。詳細は `docs/LEGAL.md`。
