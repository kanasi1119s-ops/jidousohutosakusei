# 設計

## コンセプト
フリーランス・個人事業主向けに「登録不要・データが端末から出ない・オフラインでも使える」インボイス対応請求書作成サイト。

## サイト形態
**W1（静的サイト／ブラウザ完結SPA+PWA）**。理由: 計算・文書生成のみでサーバー処理が不要。運用コストほぼゼロ。

## 企画スコア（25点満点）
| 観点 | 点 | 根拠 |
|---|---|---|
| 需要 | 4 | 2026年9月末で2割特例が終了し、個人事業主向け「3割特例」（令和9・10年分見込み）や仕入税額控除の経過措置見直しなど制度変更が続き、請求書の記載事項への関心が高い（民間解説記事による。一次情報は要確認） |
| 実装難易度 | 5 | 計算＋フォーム＋印刷で完結 |
| 法的リスクの低さ | 4 | 税務助言をしない免責を明記。第三者コンテンツなし |
| 差別化 | 3 | 無料SaaSは多いが「登録不要・オフライン・データ非送信」を軸にできる |
| 運用コストの低さ | 5 | 静的ホスティングのみ |
| **合計** | **21** | 採用基準18点以上 |

却下案: スクレイピング型価格比較（法務リスク）、ふるさと納税上限額（既存「年収の壁」と収益導線が近く、別サイクルで再スコア）、議事録AI整形（難易度高）。

## 収益化仮説（保証ではない）
無料公開＋広告/寄付、または買い切りの有料版（取引先マスタ・テンプレ・複数通貨等）。有料版のライセンスは署名付きキー方式を想定（未実装）。

## MVPスコープ
含む: 請求書作成、税率区分、印刷/PDF、保存、JSON/CSV、PWA。
含まない: 取引先マスタ、見積書・領収書、源泉徴収計算、電子インボイス(Peppol)、有料版、軽減税率の自動判定。

## 画面
単一ページ: 発行者情報 / 請求書内容+明細 / プレビュー / 保存済み一覧+バックアップ。

## データモデル
`AppData { version:1, issuer, invoices[] }`、`Invoice { id, number, issueDate, dueDate, clientName, subject, items[], rounding, note }`、`InvoiceItem { description, quantity, unitPriceYen, taxRate(10|8|0) }`（`src/model.ts`）。

## 計算ルール（`src/calc.ts`）
税率ごとに明細金額（税抜）を合計し、その合計に税率を掛けて端数処理（1請求書・税率ごとに1回）。入力は税抜のみ。
