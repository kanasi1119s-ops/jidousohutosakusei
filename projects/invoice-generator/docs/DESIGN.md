# 設計

## 企画
- コンセプト: 「開いてすぐ使える、データがブラウザから出ない、インボイス対応の請求書作成ツール」
- ターゲット: フリーランス・個人事業主・小規模事業者
- サイト形態: **W1**（サーバー不要。入力データを外部に預けたくない需要に応えるため）
- 収益化仮説（保証ではない）: 無料公開＋広告/寄付、または機能拡張版の買い切り（取引先マスタ・ロゴ・複数テンプレ）。有料版は未実装。

## スコアリング: 19/25
需要5（インボイス制度・経過措置の段階縮小で継続的な関心）/ 実装難易度3 / 法的リスク4 / 差別化2（無料の請求書ツールは多数。「登録不要・オフライン・外部送信ゼロ」が軸）/ 運用コスト5

却下案: NISA積立シミュレーター(17点: 差別化弱く金融系の免責コスト大)、議事録整形AI(15点: 難易度)。

## MVPスコープ
含む: 上記機能一覧。含まない: 見積書/領収書、取引先マスタ、ロゴ画像、税込入力、電子インボイス(Peppol)連携、有料版。

## 画面/データ
単一ページ（入力フォーム＋プレビュー）。`Invoice` 型は `src/invoice.ts`、計算は `src/calc.ts`。
