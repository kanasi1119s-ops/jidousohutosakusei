# 設計書

## 企画（PdM）
- 名称: インボイス請求書ジェネレーター / サイト形態: **W1**（サーバー処理が不要なため）
- ターゲット: フリーランス・個人事業主・小規模事業者（適格請求書発行事業者）
- コンセプト: 登録不要・データがブラウザから出ない・オフラインでも使える請求書作成
- 背景（2026-11-17時点のWeb調査、民間解説記事ベース）: 令和8年度税制改正でインボイス関連の経過措置が見直され、2026年10月以降は仕入税額控除の経過措置が80%→70%へ、2割特例は終了し個人事業者向け3割特例が新設される旨の報道・解説あり（記事間で期間・割合の記述に食い違いがあり、**国税庁の一次情報での確認が必要**）。制度理解・請求書の整備需要が継続していると判断。
- 適格請求書の記載事項（国税庁Q&A）: ①発行者の氏名/名称と登録番号 ②取引年月日 ③取引内容（軽減税率対象の旨） ④税率ごとの対価の額と適用税率 ⑤税率ごとの消費税額 ⑥交付を受ける事業者の氏名/名称。端数処理は税率ごとに請求書1枚につき1回。

## スコアリング（25点満点）
| 観点 | 点 | 理由 |
|---|---|---|
| 需要 | 4 | 制度変更で継続的な検索需要。ただし既存無料サービスは多数 |
| 実装難易度 | 4 | 依存ゼロ・印刷機能で足りる |
| 法的リスクの低さ | 4 | 第三者データ不使用。税務表示の免責が必要 |
| 差別化 | 3 | 「登録不要・外部送信ゼロ・オフライン」。機能面の優位は限定的 |
| 運用コストの低さ | 5 | 静的ホスティングのみ |
| **合計** | **20** | 18点以上のため採用 |

却下: ふるさと納税上限額シミュレーター（既存プロジェクトと収益モデルが近く、今回は見送り）。

## MVPスコープ
含む: 請求書1枚の作成・保存・出力。含まない: 見積書/領収書、取引先マスタ、自動採番、PDF直接生成（印刷機能を利用）、有料版・ライセンス認証。

## 画面
単一ページ: 基本情報 / 明細 / 操作 / プレビュー（印刷対象）/ 保存一覧。

## データモデル
`Invoice { id, invoiceNo, issueDate, dueDate, sellerName, sellerRegNo, sellerAddress, buyerName, items[{name,qty,unitPrice,taxRate:10|8}], rounding, withholding, note }`
