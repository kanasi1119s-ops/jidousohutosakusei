# 設計書

## 要件（MVP）
- 発行者情報（名称・登録番号・住所・連絡先・振込先）を一度入力すれば次回以降自動入力
- 請求書: 番号（自動採番）・発行日・支払期限・請求先・件名・明細（品名/数量/単価/税率）・備考
- 適格請求書の記載事項: 発行者名・登録番号・取引年月日・取引内容（軽減税率は ※）・税率ごとの対価合計と適用税率・税率ごとの消費税額・受領者名
- 計算: 税率ごとに合計→消費税額を1回端数処理。税抜/税込入力。源泉徴収差引
- 保存: localStorage。一覧・開く・削除（2段階確認）
- 出力: 印刷/PDF（`@media print` で請求書本体のみ）、CSV一覧（BOM付きUTF-8）、JSONバックアップ

## MVPに含まないもの
複数ページの明細、ロゴ画像、見積書・領収書、定期請求、取引先マスタ、有料版ライセンス、PDFの直接生成（ブラウザ印刷に任せる）

## 画面
単一ページ。左: 発行者情報 / 請求書内容 / 保存・出力 / 保存済み一覧 / 免責。右（PC幅）または下: 請求書プレビュー。

## データモデル（`src/model.ts`）
`AppData { version:1, issuer, nextSeq, invoices[] }` / `Invoice { id, number, issueDate, dueDate, clientName, subject, lines[], priceMode, rounding, withholding, note, updatedAt }`。
インポート時は `parseAppData` で型・長さを検証し、壊れた値は安全な既定値に補正。

## 計算（`src/calc.ts`）
整数演算のみ（数量は小数3桁まで千倍して整数化）。行金額は指定の端数処理方式で円未満を処理。
源泉徴収は税抜合計に対し 100万円以下 10.21%、超過分 20.42%、1円未満切り捨て。

## 技術
TypeScript + Vite（実行時依存ゼロ）、Vitest、Playwright。Service Worker でアプリシェルをキャッシュ（オフライン動作）。
