# 設計

## 企画（PdM）
- コンセプト: 登録不要・データがブラウザから出ない・オフラインで使える、インボイス対応の請求書作成サイト
- ターゲット: フリーランス・個人事業主・小規模事業者
- サイト形態: **W1**（サーバー不要。静的ホスティングで動く）
- 収益化仮説（保証ではなく仮説）: 無料公開＋広告/寄付、将来の買い切り有料版（テンプレート・複数請求書管理）
- 背景: インボイス制度の経過措置（未登録事業者からの仕入税額控除は2026年10月から70%へ変更される旨の報道・解説あり。国税庁原典での確認は人間が実施）等で請求書の記載事項への関心が継続

### スコアリング（25点満点）
| 観点 | 点 | 理由 |
|---|---|---|
| 需要 | 4 | 制度対応の請求書作成ニーズは継続。ただし既存SaaS/無料サイトが多い |
| 実装難易度 | 4 | 計算・書式・保存のみ。PDFは印刷機能で代替 |
| 法的リスクの低さ | 4 | スクレイピング無し。税務表現は免責と出典で対応 |
| 差別化 | 3 | 「登録不要・データ外部送信なし・オフライン」。機能面は既存に劣る |
| 運用コストの低さ | 5 | 静的サイト |
| **合計** | **20** | 採用基準18点以上 |

### 却下・保留
- ふるさと納税上限額シミュレーター: 年収の壁シミュレーターと導線が近く、スコア再計算が必要（保留）
- NISA積立シミュレーター: 次点（保留）

## MVPスコープ
含む: 発行者/請求先/明細(税率別)/端数処理選択/プレビュー/印刷/CSV/JSON/PWA
含まない: 源泉徴収税、税込単価入力、PDF直接生成、複数請求書の一覧管理、見積書・領収書、有料版

## 適格請求書の記載事項と実装
| 記載事項 | 実装 |
|---|---|
| 発行事業者の氏名/名称・登録番号 | 発行者欄（T+13桁を形式検証） |
| 取引年月日 | 発行日 |
| 取引内容（軽減税率対象の明示） | 明細＋「※」表示 |
| 税率ごとの対価の額と適用税率 | 税率別の税抜小計 |
| 税率ごとの消費税額 | 税率ごとに1回端数処理 |
| 交付を受ける事業者の氏名/名称 | 請求先名称 |

## データモデル（`src/model.ts`）
`Invoice { version, issuerName, issuerRegistration, issuerAddress, bankInfo, customerName, invoiceNumber, issueDate, dueDate, rounding, notes, items[] }`
`LineItem { name, quantity, unitPrice(税抜), taxRate: 10|8 }`。数値は±1e10まで。

## 画面
単一画面: 左=入力フォーム、右=請求書プレビュー（スマホは縦積み）。印刷時はプレビューのみ。
