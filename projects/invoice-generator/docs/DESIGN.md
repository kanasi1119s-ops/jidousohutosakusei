# 設計

## プロジェクト選定（PdM）
- 名称: インボイス請求書ジェネレーター / サイト形態: **W1**（サーバー不要、静的ホスティング可）
- コンセプト: 「登録不要・端末外に出ない・オフラインでも使える」適格請求書作成サイト
- ターゲット: フリーランス・個人事業主・小規模事業者
- 収益化仮説（保証ではない）: 広告／会計・開業支援系アフィリエイト／将来の買い切り有料版（複数テンプレート・ロゴ等）／寄付

| 観点 | 点 | 根拠 |
|---|---|---|
| 需要 | 4 | インボイス制度対応・請求書作成ツールの検索需要は継続（2026年10月は2割特例の終了時期とされる等、制度の節目で話題化。ただし一次情報は未確認） |
| 実装難易度 | 4 | 計算ロジックとフォームのみ。PDFはブラウザ印刷で実現 |
| 法的リスクの低さ | 4 | 個人情報は端末外に出ない。税務は免責明記 |
| 差別化 | 3 | 無料のブラウザ型ツールは既に複数存在。「登録不要・外部送信ゼロ・オフライン・CSP担保」で差別化 |
| 運用コストの低さ | 5 | 静的サイトのみ |
| **合計** | **20/25** | 採用（18点以上） |

却下: ふるさと納税シミュレーター（先行プロジェクトと収益導線が重複、再スコアリング要）、議事録整形（ブラウザ内AIで難易度高）

## 要件（MVP）
含む: 発行者情報、請求内容、明細（税率10/8%）、税率別集計、端数処理、源泉徴収、保存/再編集/削除、JSON入出力、CSV、印刷によるPDF、PWA
含まない: 見積書・納品書、定期請求、複数テンプレート、ロゴ画像、非登録事業者向けモード、有料版・ライセンス認証

## 画面
単一ページ: 発行者情報 / 請求内容+明細 / 保存済み一覧+バックアップ / プレビュー（印刷対象）

## 計算仕様
- 明細金額 = 数量×単価（税抜、円未満切り捨て。負数＝値引きは絶対値で処理して符号を戻す）
- 消費税 = 税率ごとの税抜小計 × 税率、**税率ごとに1回**端数処理（適格請求書の端数処理ルール）
- 源泉徴収 = 税抜合計に対し 100万円以下 ×10.21%、超過分 ×20.42%（復興特別所得税込み、円未満切り捨て）
- 請求金額 = 税抜合計 + 消費税 − 源泉徴収
