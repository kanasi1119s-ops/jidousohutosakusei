# LP草稿
## キャッチコピー案
- 「登録不要。入力した内容は、あなたのブラウザの外に出ません。」
- 「インボイス対応の請求書を、1分で。PDFでそのまま保存。」
- 「オフラインでも作れる、フリーランスのための請求書ツール」
## 特長（実装・確認済みのもののみ）
1. 登録・ログイン不要 / 入力データは外部送信なし（CSPで通信を制限）
2. 10%と8%（軽減税率）が混在しても税率ごとに集計し、消費税の端数処理は税率ごとに1回
3. 税抜・税込、端数処理（切り捨て/四捨五入/切り上げ）の切替、源泉徴収の差引に対応
4. 登録番号（T+13桁）の形式チェック
5. 「PDFとして保存 / 印刷」でA4の請求書を出力。明細CSV・JSONで書き出し/読み込み
6. 一度開けばオフラインでも動作
## 料金プラン案（仮説・要人間判断）
- 無料版: 現行機能すべて / 将来案: 買い切りで複数請求書管理・取引先マスタ・見積書・ロゴ挿入

本ツールは請求書作成の補助です。税務・法律上の助言ではなく、記載内容は利用者ご自身でご確認ください。
