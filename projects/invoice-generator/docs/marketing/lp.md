# LP草稿

## キャッチコピー案
- 登録不要。開いたら、すぐ請求書。
- 取引先の名前も金額も、あなたのブラウザの外には出ません。
- インボイスの記載項目を、迷わず入力できる請求書ジェネレーター。

## ヒーロー
**請求書ジェネレーター** — インボイス対応の請求書を作って、そのままPDFに。
会員登録なし・広告なし・オフラインでもOK。

## 特徴（実装・確認済みのことのみ）
1. **入力データは端末の中だけ** … 外部への送信はありません（外部通信を遮断する設定で配信）。
2. **登録不要・すぐ使える** … 発行者情報は一度入力すれば次回から自動入力。
3. **インボイスの記載項目に対応した入力** … 登録番号（T+13桁）の形式チェック、10%/8%（軽減税率）の税率別集計、税率ごとの消費税額表示。
4. **端数処理は税率ごとに1回** … 切り捨て／四捨五入／切り上げを選べます。
5. **源泉徴収の差し引き** … 報酬・料金等の税率（10.21% / 100万円超の部分は20.42%）で自動計算。
6. **PDFで保存** … ブラウザの印刷機能からA4で保存。
7. **オフラインでも動作** … 一度開けば、ネットワークなしでも作成できます。
8. **バックアップも自分で** … CSV・JSONで書き出し／読み込み。

## 料金プラン案（仮説・人間が決定）
- 無料: 全機能（現状の実装範囲）
- 有料版は未実装。検討する場合の案: 買い切りで「ロゴ画像・複数テンプレート・取引先マスタ」を追加

## ご注意
本ツールは請求書作成の補助です。税務・法律上の助言ではありません。記載内容は国税庁の案内等でご確認ください。
