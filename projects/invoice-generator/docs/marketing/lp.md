# LP草稿
## キャッチコピー案
- 「登録不要。入力データは、あなたの端末の外に出ません。」
- 「インボイスの記載漏れを、作る前に気づける請求書ツール」
## ヒーロー
インボイス対応の請求書を、ブラウザだけで。アカウント登録なし・オフラインでも動作。
## 特長
1. **登録不要・データは端末内のみ** — 入力内容は外部に送信されません（外部通信ゼロ）
2. **記載事項チェック** — 登録番号の形式や宛名・明細の不足をその場で警告
3. **税率ごとの消費税額を自動計算** — 10%/8%軽減を分けて集計し、端数処理は税率ごとに1回（切り捨て/四捨五入/切り上げを選択）
4. **オフラインでも使える** — 一度開けばネットワークなしで作成可能（PWA）
5. **印刷 / PDF保存・CSV・JSONバックアップ** — Excelで開いても文字化けしないCSV

## 注意書き
本ツールは請求書作成の補助です。税務・法律上の助言ではありません。記載内容の最終確認はご自身または専門家が行ってください。データはブラウザ内保存のため、定期的にバックアップしてください。
