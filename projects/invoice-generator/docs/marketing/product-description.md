# 商品説明文案（BOOTH / Gumroad 等・有料版を用意する場合の下書き。現時点は無料版のみ）

**インボイス対応 請求書ジェネレーター（買い切り・静的ファイル一式）**

ブラウザで開くだけで使える、登録不要の請求書作成ツールです。入力データは外部に送信されず、ネットワークがなくても動作します。
- 10% / 8%（軽減）/ 非課税の混在に対応し、税率ごとに端数処理を行います
- 登録番号の形式チェック、源泉徴収税額の差し引き
- 印刷／PDF保存、CSV・JSON書き出し
- 静的ファイルのため、お手元のPCやご自身のサーバーに置いて使えます

※税務上の判断は国税庁の案内や専門家にご確認ください。動作環境: 最新のChrome / Edge / Safari / Firefox。
※販売ページの公開・決済設定・特定商取引法に基づく表記は運営者（人間）が行ってください。
