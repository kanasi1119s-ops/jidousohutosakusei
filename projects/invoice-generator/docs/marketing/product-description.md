# 商品説明文案（BOOTH / Gumroad 等・有料版を出す場合の下書き）

**インボイス請求書ジェネレーター（買い切り版・案）**

ブラウザだけで動く請求書作成ツールです。インストール不要、アカウント登録不要。入力した内容は端末の外へ送信されません。

【できること】
- 10%／軽減8%／非課税の税率別集計（消費税額は1請求書あたり税率ごとに1回の端数処理）
- 税抜入力・税込入力の切り替え
- 印刷機能でPDF保存／明細のCSV出力（Excel対応）
- 請求書の保存一覧とJSONバックアップ
- オフライン動作

【ご注意】
- 税務・法律上の助言ではありません。記載内容の最終確認はご自身（または税理士）でお願いします。
- ブラウザのデータを消去すると保存内容が失われます。JSONバックアップをご利用ください。
