# 商品説明文案（BOOTH / Gumroad 等・有料版を出す場合の下書き）
**インボイス請求書ジェネレーター【静的ファイル版】**

ブラウザで開くだけで使える、インボイス制度対応の請求書作成ツールです。ZIPを展開し、お手元のPCやご自身のサーバーに置いてご利用いただけます。

■ できること
- 発行者情報・登録番号・明細の入力、10%/軽減8%の税率区分計算
- 印刷／PDF保存、CSV出力（Excel対応）、JSONバックアップ
- オフライン動作、入力データの外部送信なし

■ ご注意
- 本ツールは作成の補助です。税務上の取扱いは国税庁の公表資料または税理士にご確認ください。
- 出力された請求書の内容の適格性は、利用者ご自身の責任でご確認ください。
- 収益や節税効果を保証するものではありません。
