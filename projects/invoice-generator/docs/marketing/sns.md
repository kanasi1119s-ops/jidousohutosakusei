# SNS告知文（草稿）

**案1**
請求書を作るたびに会員登録…は、もうやめませんか？
登録不要・オフライン対応・入力データは端末の外に出ない「請求書ジェネレーター」を作りました。
10%/8%の税率別集計、登録番号の形式チェック、源泉徴収の差し引き、PDF保存に対応。
#インボイス #フリーランス #請求書

**案2**
インボイス対応の請求書、手元のブラウザだけで作れます。
取引先名も金額もクラウドに預けず、一度開けばオフラインでもOK。
CSV・JSONのバックアップも自分で管理できます。
#個人事業主 #請求書 #インボイス制度

**案3**
「税率ごとに合計してから消費税を1回だけ端数処理」を自動で。
切り捨て/四捨五入/切り上げを選べる、無料の請求書ジェネレーター。
※税務上の助言ではありません。記載内容はご自身でご確認ください。
