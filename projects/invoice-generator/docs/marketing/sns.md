# SNS 告知文（草稿）

## パターン1（機能訴求）
インボイス対応の請求書を、登録なしでブラウザだけで作れるツールを作りました。税率ごとの消費税計算（端数処理は税率ごとに1回）、印刷からそのままPDF保存。入力データはブラウザの外に出ません。 #インボイス #請求書 #フリーランス

## パターン2（プライバシー訴求）
「請求先の名前や金額をクラウドに預けたくない」人向けに、完全ブラウザ完結の請求書ジェネレーターを公開準備中です。オフラインでも動きます。※税務の助言ではありません。

## パターン3（制度話題）
2026年10月からインボイスの経過措置が80%→70%控除に。請求書の記載事項を整えたい方へ、軽減税率の「※」表記や税率別の集計に対応した請求書ツールです。最新の要件は国税庁の資料でご確認ください。
