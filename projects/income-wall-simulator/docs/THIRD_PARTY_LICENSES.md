# サードパーティライセンス一覧

## 本番（配布物）に含まれる依存パッケージ

**なし。** 本サイトはビルド後、素のHTML/CSS/JavaScript（Vanilla TypeScriptをトランスパイルしたもの）
のみで構成されており、`package.json` の `dependencies` は空です（`npm ls --omit=dev` で確認済み）。
実行時にユーザーへ配布・読み込まれるサードパーティコードはありません。

## 開発・ビルド時のみ使用する依存パッケージ（配布物には含まれない）

`license-checker` で確認した2026-09-23時点のライセンス内訳（101パッケージ、自パッケージを除く）:

| ライセンス | 件数 |
|---|---|
| MIT | 83 |
| Apache-2.0 | 7 |
| ISC | 4 |
| BSD-2-Clause | 2 |
| MPL-2.0 | 2 |
| BSD-3-Clause | 2 |
| MIT-0 | 1 |

主なパッケージ: `vite`, `vitest`, `@playwright/test`, `typescript`, `jsdom` 等。

**判定**: GPL/AGPL等のコピーレフトライセンスは検出されませんでした。すべて開発・テスト・ビルド時にのみ
使用するツールであり、配布物（`dist/`）には一切含まれないため、ライセンス条項の伝播（コピーレフト）は
発生しません。有料配布・独自利用規約での提供のいずれの形態とも衝突しません。

## 脆弱性（npm audit）

2026-09-23時点、`npm audit` で検出された5件（moderate 3 / high 1 / critical 1、いずれも
`vite`/`vitest`/`esbuild` の開発サーバー・テストランナーに関するもの）はすべて `npm audit fix --force`
（`vite` 5→8系、`vitest` 2→5系へのメジャーアップデート）により解消し、**0件**になったことを確認しました。
アップデート後、型チェック・ユニットテスト8件・E2Eテスト24件がすべて成功することを確認済みです
（`docs/DEBUG_LOG.md` 参照）。これらの脆弱性はいずれもローカル開発時のみ稼働するツールに関するもので、
配布される本番サイトには影響しません。

## 自社アイコン・アセット

`public/icons/icon.svg` は本プロジェクト用に新規作成したベクター図形であり、第三者の著作物は
使用していません。フォントは外部Webフォントを使用せず、OS標準フォント（`system-ui` 等）のみを
指定しています。
