# 法務レビュー（Phase 6）

## チェックリスト

- [x] **第三者コンテンツの権利処理**: 画像・文章・データ・フォント・アイコンはすべて本プロジェクト用に
      新規作成した自社アセットのみを使用（`public/icons/icon.svg` は独自作成のベクター図形）。
      外部フォントは使用せずOS標準フォントのみを指定。第三者の著作物・実在の人物の写真・氏名・
      SNSアカウント等は一切使用していない。
- [x] **スクレイピング**: 本アプリは対象サイトのスクレイピングを行わない（ユーザー入力のみで完結する
      計算ツールのため、そもそも該当しない）。
- [x] **個人情報の取り扱い**: 個人情報は一切取得・送信しない設計。入力データ（時給・労働時間等）は
      端末のブラウザ内（`localStorage`）にのみ保存し、サーバーへの送信は行わない。画面フッターと
      免責事項にその旨を明記済み（`src/main.ts` のプライバシーバッジ・免責事項テキスト参照）。
      プライバシーポリシーの正式な整備・公開前の最終確認は人間が行うこと（★人間確認事項）。
- [x] **免責事項・出典の明記**: 「一般的な試算であり専門税務・社会保険の助言に代わるものではない」旨を
      画面下部に恒久表示。しきい値の性質（国税庁・厚生労働省等の公表資料・報道内容に基づく一般的な
      目安であること、基準日、専門家への確認を促す文言）を `src/thresholds.ts` の `SOURCE_NOTE` に
      明記し、画面にも表示。一次情報の具体的なURLは、公開前に人間が国税庁・厚生労働省の該当ページを
      確認のうえ追記することを推奨（★人間確認事項: 現時点では一般的な報道内容に基づく記載であり、
      政府一次情報への直接リンクは未確定のため）。
- [x] **特定商取引法**: 現バージョンは無料・登録不要の提供であり、有料提供・物販は行っていないため
      現時点では該当しない。将来、有料版（ライセンスキー等）を提供する場合は特定商取引法に基づく
      表記が必要になる旨をバックログに記録済み（★人間確認事項: 実際の事業者情報の記入は人間が行う）。
- [x] **利用規約案・免責事項案**: `LICENSE` ファイルに暫定の利用規約案（現状有姿提供・免責）を記載。
      公開形態（OSS化 or 有料配布）に応じた最終版への差し替えは人間が確認・確定すること
      （★人間確認事項）。
- [x] **OSSライセンスとの整合性**: `docs/THIRD_PARTY_LICENSES.md` の確認結果（本番配布物への
      サードパーティコードの混入なし、開発ツールにコピーレフトなし）と、`LICENSE` の記載内容は
      矛盾しない。
- [x] **誇大表現の確認**: `docs/marketing/` 配下のLP・SNS文言について、「必ず得する」「絶対に損しない」
      等の断定的な効果保証表現が含まれていないことをSelf-check済み（Phase 8参照）。

## 結論・人間確認が必要な項目（★）

1. プライバシーポリシー・利用規約の正式版の整備と最終確認
2. しきい値（年収の壁の金額）について、国税庁・厚生労働省の一次情報URLの確認・追記
3. 将来有料版を提供する場合の特定商取引法に基づく表記の整備（事業者情報の記入含む）
4. 公開ライセンス形態（OSS化 or 独自利用規約での配布）の最終決定
