# 設計ドキュメント: 消費税 納税額比較シミュレーター

## 1. 背景・企画（PdMフェーズ）

- **市場調査サマリ（2026年10月5日時点、Web検索）**: 令和8年度税制改正により、インボイス制度の
  小規模事業者向け「2割特例」は個人事業者で令和8年分（2026年分）が最後となり、令和9・10年分に限り
  個人事業者の納付税額を売上税額の3割とする「3割特例」が新設された。また、免税事業者等からの仕入に係る
  経過措置は2026年10月1日から70%控除に移行する。簡易課税を選ぶ場合の届出期限（個人は2026年12月31日）が
  迫っており、「自分はどの方式が有利か」を比較したいニーズが今まさに高まっていると判断した。
- **競合**: 税理士事務所・会計ソフト各社の簡易課税計算ツールが存在するが、多くは1〜2方式の比較に留まる、
  もしくは入力がサーバーに送信される・会員登録が必要。「4方式を同時に比較」「登録不要・データ非送信・
  オフライン」を差別化軸とする。
- **ターゲット**: インボイス登録を機に課税事業者になった個人事業主・フリーランス。
- **収益化仮説**: 無料公開＋広告なし。将来は「複数年シミュレーション保存」「PDF出力」等を買い切り有料版にする、
  または寄付・スポンサー。今回のMVPには含めない。
- **サイト形態**: **W1**（計算のみで完結、サーバー不要）。

### スコアリング（25点満点、採用ライン18点）

| 観点 | 点数 | 備考 |
|---|---|---|
| 需要 | 5 | 制度改正直後、かつ届出期限（2026/12/31）が間近 |
| 実装難易度 | 4 | 計算ロジックは明確だが、端数処理・75%ルール等で検証が必要 |
| 法的リスクの低さ | 4 | 税額の一般的な試算。税務相談に当たらないよう免責・出典を明記 |
| 差別化 | 3 | 無料の計算ツールは多数。4方式同時比較・非送信・オフラインで差別化 |
| 運用コストの低さ | 5 | 静的サイト。ただし制度改正時にパラメーター更新が必要 |
| **合計** | **21/25** | 採用 |

### 却下・保留した案
- インボイス・請求書ジェネレーター（バックログ1位）: BOOTH等に「登録不要・オフライン・買い切り」の
  競合が既に存在し差別化が弱い（需要5/難易度3/法的4/差別化2/運用5 = 19）。今回は時事性の高い本案を優先し保留。
- ふるさと納税上限額シミュレーター: 収益モデルが既存の年収の壁シミュレーターと近く保留。

## 2. スコープ（MVP）

含む: 年分選択（2026〜2031）、適用要件（登録を機に課税転換・基準期間売上）、事業区分別売上（10%/8%）、
課税仕入（10%/8%）、免税事業者等からの仕入（期間別の経過措置割合）、4方式の納付税額（国税＋地方消費税）、
推奨方式の表示、簡易課税の届出期限の案内、自動保存、JSON/CSV入出力、PWA。

含まない: 法人、課税期間の短縮・暦年以外、課税売上割合95%未満の個別対応・一括比例配分、
貸倒れ・返還、1億円超の免税事業者等仕入の上限、少額特例（1万円未満）、リバースチャージ、申告書作成。

## 3. 計算仕様（`src/calc.ts`）

1. 課税標準額: 税率別の税込売上合計 ×100/110（または100/108）を千円未満切捨て。
2. 売上税額（国税）= 標準10%分×7.8% + 軽減8%分×6.24%（円未満切捨て）。
3. 本則: 控除 = 課税仕入(10%)×7.8/110 + (8%)×6.24/108 + 免税事業者等仕入×7.8/110×期間別割合。
4. 簡易: 区分別売上税額×みなし仕入率。75%ルール（1区分75%以上／2区分合計75%以上）の特例計算が有利なら採用。
5. 2割特例: 納付税額 = 売上税額×20%（2026年分のみ）。3割特例: ×30%（2027・2028年分のみ）。
6. 納付税額（国税）は100円未満切捨て、地方消費税 = 国税×22/78（100円未満切捨て）。負数（還付）は切捨てしない。
7. 推奨 = 要件上選択可能な方式のうち合計が最小のもの。

## 4. データモデル

`TaxInput`（`src/calc.ts`）: year, convertedFromExempt, baseYearSalesYen, sales10[6], sales8[6], purchases10, purchases8,
exemptPurchasesFirst, exemptPurchasesSecond。保存・JSONエクスポートはこの形式（インポート時に厳密検証）。

## 5. 画面

単一ページ: 入力フォーム → 比較結果表＋方式別備考＋届出期限 → 免責事項。375px〜1280px+対応。
