# SNS告知文（草稿）

## パターンA
2割特例は2026年分で終了。2027・2028年分は個人事業主向けの「3割特例」、その後は簡易課税か本則か…。
自分の場合の納税額を4方式で並べて比較できるツールを作りました。登録不要・入力データはブラウザの外に出ません。
※一般的な試算です。最終判断は税理士等にご確認を。 #インボイス #消費税 #個人事業主

## パターンB
簡易課税に切り替えるなら、届出は「適用したい年の前年12月31日まで」。2027年分から使いたい方は2026年12月31日が期限です。
「結局どれが一番納税額が少ないの？」を1画面で確認できます（試算は目安です）。 #確定申告 #フリーランス

## パターンC
オフラインでも動く、消費税の納税額比較ツール。免税事業者からの仕入の経過措置（70%控除への移行）も反映。
入力した売上・仕入は端末の中だけに保存されます。 #インボイス制度 #経理
