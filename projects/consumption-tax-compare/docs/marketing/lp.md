# LP草稿: 消費税 納税額比較シミュレーター

## キャッチコピー案
- 「2割特例」の次は？ 本則・簡易・3割特例の納税額を、1画面で並べて比較。
- インボイス登録した個人事業主のための、消費税 納税額の比べ方ツール。
- 登録不要。入力した数字は、あなたのブラウザの外に出ません。

## こんな方に
- インボイス登録を機に課税事業者になった個人事業主・フリーランス
- 2026年分で2割特例が終わるため、2027年分以降の納税額の見通しを立てたい方
- 簡易課税を選ぶか迷っている方（届出期限は適用したい年の前年12月31日）

## 特長（実装・確認済みの事実のみ）
1. **4方式を同時に比較**: 本則課税・簡易課税・2割特例・3割特例を、国税＋地方消費税の合計で並べて表示。
2. **要件の自動チェック**: 年分、基準期間の課税売上高、登録を機に課税転換したか、で選べる方式を判定。
3. **経過措置にも対応**: 免税事業者等からの仕入の控除割合（80%→70%→50%→30%→0%）を期間別に反映。
4. **簡易課税の75%ルール**に対応（事業区分が複数でも有利な計算を採用）。
5. **登録不要・データ非送信・オフライン対応**: 入力値は端末のブラウザ内にのみ保存。
6. **Excelで開けるCSV出力**、設定のJSONバックアップ。

## ご利用上の注意（LPにも掲載すること）
一般的な試算であり、税務申告や税理士による個別相談に代わるものではありません。制度は令和8年度税制改正に基づく目安で、
基準日は2026年10月5日です。実際の判断前には国税庁等の最新情報・税理士にご確認ください。
