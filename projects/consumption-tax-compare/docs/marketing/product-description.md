# 商品説明文案（有料版を出す場合の下書き／現時点は無料公開想定）

**消費税 納税額比較シミュレーター（買い切り版・仮）**

インボイス登録をした個人事業主向けに、消費税の納税額を「本則課税」「簡易課税」「2割特例」「3割特例」で並べて比較できる、
ブラウザで動くツールです。インストール不要・アカウント登録不要。入力した数字は外部に送信されず、オフラインでも使えます。

【できること】
- 4方式の納付税額（国税＋地方消費税）を同時に比較
- 事業区分（第1〜6種）別の売上入力、簡易課税の75%ルールに対応
- 免税事業者等からの仕入の経過措置（控除割合の段階的縮小）を反映
- CSV（Excelで文字化けしないUTF-8）・JSONで保存

【ご注意】
一般的な試算ツールです。税務申告書の作成や税務相談を行うものではなく、結果の正確性・節税効果を保証するものでもありません。
法人・課税期間が暦年でない場合などは対象外です。最終判断は税理士等の専門家へご相談ください。
（特定商取引法に基づく表記は販売時に人間が記載）
