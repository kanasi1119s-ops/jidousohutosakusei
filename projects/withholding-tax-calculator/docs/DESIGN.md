# 設計

## 企画（PdM）
- コンセプト: 「請求書を受け取ったその場で、源泉徴収額と振込額がわかる」
- ターゲット: 小規模事業者・経理担当・フリーランスに外注する個人／法人
- サイト形態: **W1**（計算のみでサーバー不要。データは端末内に留める価値が高い）
- 収益化仮説（保証なし）: 広告、既存 invoice-generator への導線、将来の買い切り有料版（一括CSV取り込み等）
- MVP含む: 2区分の計算、消費税区分の有無、複数明細、JSON/CSV入出力、PWA
- MVP含まない: ホステス等・芸能人・司法書士等の特例計算、印刷用帳票、有料版ライセンス

## 計算ロジック（src/rules.ts, src/calc.ts）
- 消費税 = floor(報酬×税率/100)、請求額 = 報酬+消費税
- 対象額 = 区分あり ? 報酬 : 請求額
- 源泉 = 対象額≤1,000,000 ? floor(対象額×1021/10000) : floor((対象額−1,000,000)×2042/10000)+102,100（整数演算で浮動小数誤差を回避）
- 支払額 = 請求額 − 源泉
