# 源泉徴収税額かんたん計算

原稿料・講演料・デザイン料、弁護士・税理士等への報酬を支払うときの**源泉徴収税額と支払額**を計算する、ブラウザ完結の静的サイト（W1）です。登録不要・入力データは外部送信なし・オフライン動作（PWA）。

- 税率: 100万円以下 10.21%／100万円超の部分 20.42%（復興特別所得税込み）。円未満切り捨て
- 請求書で報酬と消費税が区分されていれば税抜額、区分されていなければ税込額を対象に計算
- 複数明細の管理、JSONエクスポート／インポート、CSV（BOM付きUTF-8）ダウンロード

## 起動・テスト・ビルド
```
npm ci
npm run dev        # 開発サーバー
npm run check      # 型チェック
npm test           # ユニットテスト(Vitest)
npm run test:e2e   # E2E(Playwright。ビルド後にpreviewを起動して実行)
npm run build      # dist/ に静的ファイルを出力（相対パス）
```

## データの保存場所
ブラウザの localStorage（キー `withholding-tax-calculator:entries:v1`）のみ。バックアップはJSONエクスポートで行ってください。

## 対象外
ホステス等・芸能人・司法書士等の報酬、非居住者への支払い、源泉徴収の要否判断。詳細は `docs/DESIGN.md` と `docs/LEGAL.md`。
