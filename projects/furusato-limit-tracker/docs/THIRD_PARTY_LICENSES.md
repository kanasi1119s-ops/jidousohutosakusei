# サードパーティライセンス

## 配布物（dist/）に含まれる依存パッケージ
**なし。** `dependencies` は空で、実行時に配布されるサードパーティコード・フォント・画像はありません。アイコンは本プロジェクトで作成したSVGです。

## 開発・テスト時のみ使用（配布されない）
`license-checker` による2026-11-02時点の内訳（101パッケージ、自パッケージ含む）:
MIT 82 / Apache-2.0 7 / MPL-2.0 3 / ISC 3 / BSD-2-Clause 2 / BSD-3-Clause 2 / MIT-0 1 / UNLICENSED 1（自パッケージ）。
GPL/AGPL等は検出なし。MPL-2.0 は開発ツールとしての利用のみで配布物に含まれないため、提供形態と衝突しません。
