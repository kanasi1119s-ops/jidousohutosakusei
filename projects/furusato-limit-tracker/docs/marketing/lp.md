# LP草稿

## キャッチコピー案
- 「上限の目安を出して、寄附を書き留める。ふるさと納税の年末ノート。」
- 「あと何円まで？が、ひと目で分かる。」
- 「登録なし。入力した金額は、あなたの端末から出ません。」

## ヒーロー
年収などを入れるだけで、ふるさと納税の控除上限額の目安を表示。寄附するたびに記録すれば、年末までの残り枠と、ワンストップ特例の条件（寄附先5自治体以内）を確認できます。

## 特長（実装・確認済みのもののみ）
1. **登録不要**: アカウント作成もログインもありません。
2. **入力データは端末の外に出ません**: 外部通信を技術的に禁止（CSP）。保存先はお使いのブラウザ内です。
3. **オフラインでも使える**: 一度開けば、通信なしでも動作します。
4. **残り枠が分かる**: 複数のサイトで寄附しても、合計と上限までの金額を一か所で確認。
5. **ワンストップ特例の条件チェック**: 寄附先が6自治体以上になると警告。
6. **CSVで書き出し**: Excelで文字化けしにくいUTF-8（BOM付き）。確定申告の準備メモにも。
7. **スマホ対応**: 375px幅から快適に操作。

## 使い方
①年収などを入力 → ②上限額の目安を確認 → ③寄附のたびに記録 → ④年末前に残り枠を確認

## 料金プラン案（仮説・要人間判断）
- 無料: 本機能すべて。
- 将来案: 複数年の履歴・PDF出力などの買い切り版（未実装）。

## 注意書き
表示額は概算です。実際の上限は、住宅ローン控除・副業・事業所得などで変わります。税務上の助言ではありません。ご自身の源泉徴収票・住民税決定通知書、自治体・税務署の案内で確認し、余裕を持った寄附をおすすめします。
