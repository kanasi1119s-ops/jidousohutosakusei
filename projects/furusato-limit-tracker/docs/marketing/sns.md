# SNS告知文（草稿）
**案1（実用）**
ふるさと納税、あと何円まで寄附できる？を端末内で完結して確認できるツールを作りました。登録不要・入力データは外部送信なし・オフラインOK。上限の目安は年収などから概算、寄附は記録して残り枠を表示します。※概算です。
#ふるさと納税 #年末調整

**案2（年末駆け込み向け）**
複数のサイトで寄附して「合計いくらだっけ？」となりがちな年末に。自治体・日付・金額をメモすると、上限までの残り枠と「ワンストップは5自治体まで」のチェックが出ます。CSVで書き出しもできます。

**案3（プライバシー訴求）**
年収を入れるのはちょっと…という方へ。このツールの入力内容はあなたのブラウザの中だけに保存され、外には送られません（通信自体を禁止する設定にしています）。
