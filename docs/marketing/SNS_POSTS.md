# SNS告知文（草稿）

## パターン1（機能訴求）

```
ふるさと納税、今年の上限額いくらか知ってる?

年収と家族構成を入れるだけで、控除上限額(概算)がその場でわかる
シミュレーターを作りました。

・登録不要
・入力データは外部に送信されない(ブラウザ内のみ)
・オフラインでも使える

#ふるさと納税 #節税 #個人開発
```

## パターン2(プライバシー訴求)

```
年収を入力するツールって、データがどこに送られるか気になりませんか?

このふるさと納税シミュレーターは、入力した年収も計算結果も
あなたのブラウザの中だけに保存されます。サーバーには一切送信しません。

登録も不要、今すぐ試せます。

#ふるさと納税 #プライバシー
```

## パターン3(季節訴求)

```
ふるさと納税の締め切りは12月31日。
「今年の上限額、まだ確認してない…」という方向けに、
年収と家族構成だけでサッと概算がわかるシミュレーターを作りました。

無料・登録不要・データはブラウザ内のみです。

#ふるさと納税 #年末
```

## Self-check（誇大表現の有無）

- いずれの文案も「概算」であることを明記し、「必ず得する」等の断定表現は使用していません。
