# LP（ランディングページ）文案

## メインキャッチコピー（3案）

1. **「年収を入れるだけ。ふるさと納税の上限額が、その場でわかる。」**
2. **「登録なし、送信ゼロ。あなたの年収データは、あなたのスマホから出ません。」**
3. **「毎年恒例のあの計算、今年は2,000円の自己負担で終わらせよう。」**

## サブコピー

- 会員登録不要・メールアドレス不要。開いてすぐ使えます。
- 入力した年収・家族構成は、あなたのブラウザの中だけに保存されます。運営者にも送信されません。
- 一度開けば、電波の悪い場所でもオフラインで使えます（PWA対応）。

## 機能一覧（訴求用）

| 機能 | 説明 |
|---|---|
| かんたん入力 | 年収と家族構成を選ぶだけで、控除上限額(概算)をすぐ表示 |
| データはブラウザの中だけ | サーバーに送信しない設計。プライバシーを気にせず使える |
| オフライン対応 | 一度開けば、通信環境が悪くても操作できる |
| 記録の保存・比較 | 複数パターンを保存して見比べられる |
| CSV/JSONエクスポート | 保存した記録はいつでも自分のPCにバックアップできる |
| 完全無料・広告なし（現時点） | 追加費用なしで使える簡易シミュレーターです |

## 料金プラン案

現時点では**完全無料**（広告なし）で提供する想定です。将来、より詳細な計算モード
（住宅ローン控除・医療費控除対応など）を有料オプションとして追加する可能性がありますが、
現行の基本機能は無料のままとする方針です（最終的な価格設定・課金開始は人間が判断・実施）。

## 訴求文で避けている表現（Self-check）

- 「必ず得する」「絶対にお得」等の断定的な効果保証表現は使用していません。
- 「概算」「目安」であることを一貫して明記し、正確な金額は専門家に確認するよう案内しています。
